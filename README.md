# 云径 CloudPath

把教材整理成课程，在 iPhone 或 iPad 上按章节学习、练习和复习。

## 开始使用

1. **首次进入**：按页面提示登录，填写称呼、学习目标、每日学习时间等偏好；之后可在「我的」中修改。
2. **添加课程**，任选一种方式：

   - 在「发现」选择已有课程，点击「导入到我的课程」，按提示完成设置。
   - 在首页点击「创建课程」，选择 PDF，点击「保存资料并继续」，按提示完成解析、课程设置、目录确认和学习诊断。

3. **开始学习**：选中课程，点击「继续学习」，或从目录选择章节。点击「回到原书」查看教材；遇到问题可点击「问问 AI」，查看回答中的原文引用。
4. **巩固知识**：完成章节练习，在「错题集」回顾错题；进入「闪卡复习」，点击卡片查看答案，再选择「记住了」或「还不熟」。
5. **记录笔记**：在「学习笔记」点击「新建笔记」，记录文字、手写批注或语音。语音点击「结束并生成笔记」后，会在后台识别并由 DeepSeek Flash 整理，直接展示并保存笔记，无需核对逐字稿；原始录音保留供回放。也可从笔记返回关联的教材原页。
6. **分享教材**：在「发现」右上角点击「分享」，或在课程资料中点击「分享」，选择自己上传并解析好的 PDF，填写可选简介、确认分享权限后发布。其他人可以导入原 PDF；个人笔记和学习进度不会随教材公开。已发布的教材可在同一窗口撤回。

## 使用提示

- 首次登录、导入课程、教材解析、课程生成和 AI 答疑需要联网及相应服务。若提示服务未就绪，按页面说明处理后重试。
- 暂时断网时可继续阅读已缓存内容；学习进度在恢复连接后重试同步。个人笔记保存在当前设备，暂不支持跨设备同步。
- 连接失败时，检查网络或 VPN，并在登录页右上角「设置 → 学习服务地址」确认服务地址；账号会话失效时需重新登录。
