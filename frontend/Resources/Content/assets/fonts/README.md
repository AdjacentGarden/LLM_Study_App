# Noto Sans SC

`NotoSansSC-400.woff` and `NotoSansSC-700.woff` are static Regular and Bold
web fonts generated from the Noto Sans SC variable font for consistent rendering
in the app's WebKit preview and offline builds. The font is distributed under
the SIL Open Font License 1.1; see [OFL.txt](./OFL.txt).

Upstream: https://github.com/google/fonts/tree/main/ofl/notosanssc
