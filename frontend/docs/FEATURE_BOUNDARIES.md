# 原生功能与验收边界

普通启动使用真实本机存储与可配置的 FastAPI 后端。新用户不会自动得到示例教材、示例笔记、预填错题或虚拟积分；社区目录不使用打包清单补齐。固定输入仅供 Debug 自动化测试显式注入，Release 忽略 `--fixture`。

| 范围 | 当前代码行为 | 验收边界 |
| --- | --- | --- |
| 我的书 | 原文件先复制到本机，再上传处理副本；上传失败保留本机书籍、草稿和原件；缓存恢复保留待上传课程 | 本机清单不是整个后端公开目录；仅取得服务器访问权不代表原件已经下载 |
| 社区 | 从后端读取真实发布目录；支持已有真实生物课程与已公开教材分享 | 无本地预置书单、虚构评论和学习人数；空目录和断连显示真实状态；不自动给新用户分书或发布教材 |
| 本地提取 | PDF 文字层、图片完整解码、Office XML、UTF-8 文本 | 只标记 `source_ready`，不生成页面伪章节、AI 课程、固定日程或满分置信度；扫描件不假装完成 OCR |
| OCR、诊断与课程 | 使用后端真实解析、诊断、生成及持久结果 | 需要已配置的服务与模型；不可用时保留原件并报错，不能回退到演示答案 |
| 原文阅读 | PDFKit、真实原页、页码及引用回跳；本机原件可直接打开 | 保留已有生物课 125 张真实原页及其缺章标记；不从其他教材补造证据 |
| 答疑 | 在线资料调用后端 RAG；本机资料支持真实原文检索，并明确标注离线摘录 | 离线不运行大模型，也不虚拟扣积分；不存在的教材 ID 不映射到生物教材 |
| 文字、笔迹与录音 | 本机保存原稿；支持原生编辑、PencilKit 批注、录音及试听 | 原稿不依赖识别服务；不提供示例录音按钮或固定转写 |
| 语音笔记 AI | 显式结束并生成后，后台 ASR → DeepSeek `deepseek-flash` 整理 → 自动保存最终笔记；列表、详情和导出不展示原始逐字稿 | 原音保留，重开不新建生成请求；需关联有访问权的教材并配置 DeepSeek 与本地 ASR；含糊内容可标待补充 |
| 手写笔记 AI | 上传实际笔画，识别后确认文字再整理；采用结果后保存本机新版本 | 需关联已上传且有访问权的教材；原笔迹始终保留；跨设备原稿同步尚未实现 |
| 图片与视频 | 真实 Studio 请求、精确任务查询、认证下载、实际成品展示与缓存 | 服务缺失、失败或未知结果如实展示；请求回执先保存，未知提交不自动重投；既有真实教材配图可继续使用 |
| 练习、闪卡、错题与计划 | 使用实际教材内容、用户作答；在线课程通过每日排程接口获取任务、时间预算与确认状态，完成事件持久化并幂等同步 | 不编造默认错题、进度或每日任务；无可安排内容时显示空状态，读取失败保留最近缓存并提供重试 |
| PDF 导出 | 从所选的现有教学内容、引用及文字笔记实际生成多页 PDF，供系统保存或分享 | 空内容报错；手写和录音原件不伪称已嵌入 PDF |
| 系统日历 | 尚未接入 | 已移除“加入日历”的假成功按钮 |
| 历史预览升级 | 未修改的客户端预览记录先归档，再移出可见列表 | 保留已有真实原件映射、编辑内容和用户笔记；不删除现有后端用户资料 |

## 真实资源与测试数据

原有教材配图、字体、图标和原页是实际资源，不因清理演示逻辑而删除。源数据中缺失的 267 条插图引用继续明确记录，既有 23 张 AI 图与 125 张原页保留；不生成占位图冒充教材原图。

`Resources/Data` 中的旧固定输入用于隔离回归和历史预览迁移识别，普通启动不注入。测试替身只能用于测试依赖，不能根据服务失败动态选择。后端访谈样本已移到 `backend/tests/demo_book_fixture.py`，生产启动不再安装不存在的 `demo.pdf`。

## 本轮验证范围

使用真实后端仓库、HTTP、权限与任务状态测试；模型服务通过隔离的测试适配器检查失败、状态和幂等合同，没有重新调用收费模型。Swift 已做主机类型检查、真实 SQLite/文件恢复和网络合同检查，PDF 的 CoreText 分页与内容保留也已执行验证。

当前主机没有完整 Xcode/iOS SDK，新增 XCTest、PencilKit、UIKit 页面及录音权限仍需在 Xcode 和 iPhone 上验收。主机检查不等于已完成 iOS 构建、签名或真机安装。本次源码变更也不表示已升级服务器的现有运行实例。
