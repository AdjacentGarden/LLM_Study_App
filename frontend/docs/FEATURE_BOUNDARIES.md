# 真实能力与演示边界

普通启动已切换到[云端 P0 接入模式](CLOUD_INTEGRATION.md)：本地默认账号（可切回邮箱认证）、多资料工作区、PDF 服务端解析、个人目录、真实诊断、章节课程、教材答疑和进度恢复使用 FastAPI。云端模式不加载本表中的示例教材，也不使用本地规则替代服务端评分。未安装 OCR/模型时可以登录和保存 PDF，后续生成与答疑需要配置对应服务。下表继续记录原有离线 fixtures 的行为。云端笔记目前只按账号隔离保存在本机；社区课程发布、好友客户端和积分计费尚未接入。

本仓库是原前端的原生迁移，保留仓库内示例数据与既有演示流程，同时落实设备本地存储、阅读、文件导入和原生教材检索。界面中的“生成”“识别”“整理”等既有文案，不代表已经接入通用生产服务；以下边界应作为开发与验收依据。

| 范围 | 已实现行为 | 当前边界 |
| --- | --- | --- |
| 28 个页面与 6 类全局弹层 | SwiftUI 原生路由、iPhone/iPad 自适应、原字体和图标、原页面交互 | 视觉验收以原 WebKit 基线与同尺寸截图比较，排除系统状态栏差异 |

| 资料导入 | 系统选择器、复制原件、解析进度、cancelImport 取消并丢弃过期回调、失败重试、PDF/图片/Office/文本本地提取 | 扫描件不做 OCR；Office 提取文本而非精确排版 |

| 闪卡、练习、诊断、错题、计划 | 闪卡翻面/手势、提交答案、规则评分/固定题库诊断、错题持久化与计划进度 | 不进行在线阅卷或对任意简答题作可靠语义评分；题库/解释来源为现有示例 |

| 导出、日历 | 保留预览与界面演示反馈 | 当前未生成可分享的正式 PDF 或写入系统日历 |
| 个人与设置 | 本机偏好、显示信息与操作状态 | 退出是本机界面/偏好流程，没有远端鉴权或支付 |

## 资源事实

源数据的 290 条生物 asset 记录中，267 条 extracted figure 指向源 public 中不存在的 `assets/textbook/figures/*`。原网页加载失败即不显示，新前端也仅布局真实存在的图片。保留 23 个已存在 AI 图以及 125 张教材原页，不凭空画图、借用别书或生成占位来掩盖来源缺失。`References/resource-copy-manifest.json` 列出每一条已知缺失引用，校验器拒绝新增未知缺失。

## 验收建议

固定场景应使用隔离的 `--fixture-session`，完成所有路由、弹层与关键流程回归；同时用正常持久化模式验证重启、资料取消/失败、无麦克风权限、存储失败、切书引用、扫描 PDF、混合资料与积分退款。视觉比较使用与 `References/VisualBaselines/manifest.json` 对应的 viewport / book / chapter / fixture，并记录原素材不可用时的同等行为。

按最低 iOS 17 与当前系统、iPhone 与 iPad 分别执行测试；有模拟器验证记录不等于真机麦克风、Apple Pencil、内存压力或所有系统版本都已完成验收。需要发布时，还应落实签名、内容授权、隐私说明与真实服务范围；这些属于交付后的发布工作，不能从本地 Demo 的按钮状态推断已具备。
