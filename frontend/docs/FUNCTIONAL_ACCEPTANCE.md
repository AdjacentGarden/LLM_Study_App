# 功能与动效验收

验收范围按用户最新要求执行：不再检查与旧Web界面一比一或逐像素还原。检查对象是原生App的实际用户操作、状态流转、持久化、错误/取消处理及关键动效完成后仍可继续操作。测试使用隔离fixture目录，只使用仓库教材和生成的测试样本，不读取设备个人资料。

最终统一批次于2026-10-21 05:24:55 PDT完成：**67项单元／集成＋16项UI＝83项通过，0失败、0跳过**。原始[摘要](../References/Validation/functional-delivery-summary.json)与[逐项耗时](../References/Validation/functional-delivery-tests.txt)已归档；构建和平台记录见[VALIDATION.md](VALIDATION.md)。

## 可重复执行

```bash
python3 scripts/validate-content.py
scripts/test.sh --device SIMULATOR_UDID --all --result output/functional.xcresult -- ARCHS=arm64
```

## 平台与边界

部署目标严格为iOS/iPadOS17.0，设备与模拟器Mach-O最低版本都做实际检查；本机只有26/27模拟器runtime，未把26上的通过写成17运行通过。实体麦克风、系统音频中断和Apple Pencil未执行，样例音频和手指输入不替代这些硬件结果。

默认离线；个人Key在线模型未实际调用。转写/整理、手写识别、规则诊断、日历Toast与PDF导出预览保持原演示边界，不宣称真实OCR、云同步或实际PDF文件导出。真机权限拒绝、低磁盘、系统文档提供者和真实强杀时机仍需要相应外部环境；已有本机失败/取消/重启单测不冒充完整硬件测试。

历史Web/原生图片只为追溯，像素差异不参与当前验收；中断的截图采集不会标成完成。
