# 前后端深度优化与验证 · 2026-09-04～05

## 本轮范围

在 adaptive-book-learning-app 上修改；未修改旧 LLM_Study_App 仓库，未提交 GitHub。
遵循界面设计技能的工作界面优先、可读性和真实反馈原则，保留现有 React 依赖和素材。
后端继续运行在 4090 数据盘，未迁移数据库、覆盖教材或重新初始化用户画像。

## 前端

- 首页收紧重点课程区域，章节支持“全部 / 优先巩固”切换，数据使用真实诊断估计。
- 页面进入、章节标签、筛选卡片和回答段落使用分层动画；闪卡支持跟手位移、轻微旋转、松手回弹和翻面。
- 动画与导航提交解耦。回归中发现原生快照转场在快速点击与视口变化叠加时可能丢操作，已替换为不阻塞状态更新的 CSS 入场；减少动态效果偏好仍受尊重。
- 章节长标题换行而非省略；书架不再用写死的生物封面，不冒称所有书均已高精度处理。
- 问题建议从当前书的章节或完整短知识点产生，无适合的短知识点时退回章节问题，不截断概念。
- 答疑建议可收起，为正文留空间；发送后清空输入，失败可恢复问题并重试，Shift+Enter 换行。
- 答案按事实段落呈现，原文依据可展开；仅在后端确实完成语义审校时显示对应状态。
- 加入初始加载骨架、断网提示、请求超时、结构化错误转换、渲染异常恢复界面。
- 不自动重发写请求，避免超时后重复保存评分；暂时断网/5xx 不再清除学习会话。
- 知识点的未验证先验不再展示为 50% 掌握率；标题与正文相同时去重，练习展示已覆盖和待补充的具体要点，并区分低置信评分。
- 恢复会话时匹配其书籍；每本书保存独立会话入口；浏览器存储不可用时不使页面崩溃。

## 后端

- 除逐字引用核验外，新增独立模型语义审校，检查主体、否定、条件、数字、单位和因果方向。覆盖遗漏、重复索引、非布尔判定、错误引用和不受支持的结论均不放行；失败后修正并再次审查。
- 简单定义题最多 3 条事实，保留审校但省去不必要的覆盖规划调用；复杂问题仍规划证据覆盖。避免一个定义问题扩写成整章实验史。
- 引用空白字符串不能绕过逐字验证；去掉同页被较长引文完全包含的重复短引文。
- 同一本书、同一问题的并发请求合并；支持答案缓存最多 64 条、有效期 5 分钟，不缓存失败和证据不足结果。实例与索引隔离，不跨书共用答案。
- 最多 3 个不同问题同时生成，超载返回可重试 503 和 Retry-After。缓存结果深复制，调用方不能改坏后续结果。
- 模型 HTTP 连接池复用；处理空 choices、空内容、错误 JSON、网络和协议故障；规划、回答、审校及重试共享 120 秒剩余时间预算。
  HTTPX 的该预算用于各阶段请求超时，并非能强行终止所有底层线程的硬实时期限。
- 大响应启用 gzip；首页 HTML 要求缓存重新验证，避免浏览器长期使用旧资源入口。
- 知识点标题保留完整概念及条件，不按逗号或 36 个字符截断。课程指纹纳入生成器版本，使旧草稿按需刷新，原学习记录不删除。

## 边界与后续验证

本轮显著补齐了前后端行为、容错和证据审校，但不宣称“所有书、所有功能、所有故障都已完美”。
模型审校仍有概率误判，原文自身若有 OCR 错字或事实错误，逐字一致和语义一致不能独立证明事实真实。
部署的真实 RAG 索引仍是这本生物教材，其他书必须完成各自 OCR、章节重建和索引接入；不会自动借用生物索引回答其他书。
跨语言、多栏、公式密集和低清扫描书还需要各自整书评测；没有把短原文测试包装成普适性已完全解决。
浏览器模拟验证不等于 Android/iOS 实机键盘、无障碍服务和系统通知认证。学习提醒仍是本机偏好，不冒称已有系统推送。
