## 接口与兼容

导入教学包是可选能力：普通教材继续走原编译路径。导入包身份、PDF 哈希、实际原文页和块范围必须一致；两种旧来源哈希字段兼容但冲突时拒绝。讲解置于原文摘录前，保留引文和 AI 整理标记；题目答案只存在于私有评分模型，不随公开题目响应发送。教学包或配图索引变化参与课程来源指纹，旧课程历史与原题重做仍按旧版本处理。

本地配图由 `GET /api/books/{book_id}/imported-assets/{asset_id}` 提供，每次检查教材拥有关系；拒绝目录穿越、外链、未知文件和不支持的媒体类型。视频支持 Range 请求。补充内容 GET 只返回讲解、卡片题面与练习题面，不含答案或虚构源页；翻卡与练习核对由书架归属校验后的独立 POST 接口返回答案。简答题仅展示参考答案，不伪造自动语义评分。选择／判断题的补充错题 ID 仅保存在当前浏览器的账号隔离存储中，不写入正式课程或学习记录。
