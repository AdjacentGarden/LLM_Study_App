# 技术架构：从扫描书到个人课程

## 1. 产品目标与边界

核心卖点不是“把 PDF 接到聊天模型”，而是：对任意书籍先重建可信内容，再用尽可能少、但信息量最大的互动识别用户在这本书上的真实起点，最终生成能够持续变化的个人课程。

系统明确区分三种数据：

- **用户声明事实**：目标、学习经历、时间约束、重点章节，由用户输入并可编辑。
- **行为证据推断**：知识掌握、误解候选、信心校准，由多次回答形成后验分布。
- **尚未知**：证据不足就保持未知，不用大模型猜测。

系统不推断人格、智力、心理健康、政治倾向等与教学无关的敏感特征。画像是“针对当前书籍的学习状态”，不是对人的永久标签。

## 2. 总体数据流

```text
上传 PDF
  -> 文档指纹与安全检查
  -> 页面判型（数字 / 扫描 / 混合）
  -> 高分辨率渲染与版面恢复
  -> 多候选 OCR/VLM 识别
  -> 块级对齐、质量评分与低质量救援
  -> LLM 邻页校对 + 修订账本
  -> 章节边界、整书摘要、章节摘要
  -> 可追溯块索引与诊断题库
  -> 主动访谈 + 自适应诊断
  -> 用户确认学习画像
  -> 章节个性化策略
  -> 原文阅读 / 总结 / 知识点 / 闪卡 / 练习 / RAG 答疑
  -> 学习行为继续更新后验并局部重编课程
```

可见目录只到“章”。内部允许知识点图谱，因为诊断和检索需要更细的证据单元，但不会强迫所有书都具备“节”结构。

## 3. 高精度文本重建

### 3.1 页面自动判型

`PDFInspector` 同时检查：

- 原生文字字符数和文本块数量；
- 页面内图像数量与图像面积覆盖率；
- 字体对象、文本坐标和异常编码迹象；
- 页面旋转、尺寸和重复页。

判型不依赖文件名或学科。数字页优先使用原生文本并校验阅读顺序；扫描页进入 OCR；混合页分别处理原生块和图像块再合并。

### 3.2 主解析器与救援解析器

主解析器采用 MinerU sidecar。它适合输出有阅读顺序、坐标、表格、公式和插图关系的结构化块。Docling 保留为格式扩展和交叉验证适配器，负责 DOCX/PPTX/HTML 等输入，避免核心域模型依赖单一厂商输出。

扫描页流程：

1. 以 300 DPI 渲染，自动旋转、去倾斜、轻度去噪和对比度增强；
2. 主模型生成布局、文字、公式、表格和图片区域；
3. 质量低于 `0.72` 的页在 420 DPI 重试；
4. 只对可疑块做视觉模型救援，不重复处理整本书；
5. 两个候选按坐标和文本相似度对齐，差异过大则标为待核验；
6. 任一模型的“高置信”不能覆盖跨模型严重冲突。

这样能把 GPU 成本集中在真正困难的 5%-20% 页面，而不是对所有页重复调用昂贵视觉模型。

### 3.3 五维质量门控

每页计算：

- `character_score`：非法字符、替换字符、乱码模式；
- `language_score`：中文/英文语言连贯性、异常单字母串、重复模式；
- `layout_score`：极短碎片、超长行、栏序和标题层级；
- `coverage_score`：检测区域与输出块覆盖；
- `agreement_score`：主候选与第二候选的一致度。

使用加权几何平均而非简单平均，防止某项极差被其他高分掩盖。最终分为：

- `accepted >= 0.90`：可进入章节重建和 RAG；
- `review 0.72-0.90`：允许 LLM 清洗，但保留警告；
- `rescue < 0.72`：必须复识别，不能直接面向用户。

阈值需要用真实标注集校准，不把当前经验值当永久真理。

### 3.4 LLM 二次校对不是自由改写

清洗器同时读取前页末尾、当前页和后页开头，仅用于断句与跨页判断。返回：

- `cleaned_text`；
- `edit_ledger`：每次修改的前后内容、类型和原因；
- `unresolved_fragments`：无法确认的片段。

禁止用模型常识补书中没有的事实。清洗后重新跑质量评分；存在未决片段时即使得分高，也最多进入 `review`。

### 3.5 可追溯存储

每个 `TextBlock` 保留 `book_id / page_number / block_id / bbox / source_method / confidence`。用户看到的总结、知识点和回答引用 `block_id`，但界面只显示“第 N 页原文”，不展示内部 chunk ID。

建议生产存储：

- 对象存储：原 PDF、页面图、可视化版面检查图；
- PostgreSQL：书籍、页、块、章节、质量记录、修订账本；
- pgvector 或 Qdrant：密集向量；
- Redis：任务状态、限流、短期会话；
- GPU worker：MinerU/VLM；CPU worker：预处理、质量统计和索引。

## 4. 整书理解与通用章节结构

章节重建使用“规则候选 + 模型核验”：

1. 从目录、字号、标题模式、页眉和主题变化找候选边界；
2. 目录页只提供候选，必须与正文标题或内容转折核验；
3. 模型只允许选择已有页和块；
4. 章节区间必须连续、合法并能回指来源；
5. 没有明确章节的书退化成“全书内容”一章，绝不伪造结构。

整书摘要采用 map-reduce：页面块摘要 -> 章节摘要 -> 全书摘要。每层都保留来源集合，减少超长上下文成本和事实漂移。

## 5. 主动学习者诊断

### 5.1 用户看到的流程

1. AI 用自然语言介绍全书主题与章节；
2. 问本次学习目标、重点章节和时间约束；
3. 问与书相关的已有经历，不做泛化人格问卷；
4. 用 5-12 个自适应任务定位掌握程度；
5. 展示“已确认 / 推测中 / 尚未知”的画像，让用户纠正；
6. 生成课程，此后的闪卡、练习和问答继续更新画像。

每题提供“为什么问这个”，降低被审问感。用户可选“不知道”，这也是有效证据。

### 5.2 冷启动先验

每个知识点使用 Beta 后验：

```text
mastery_k ~ Beta(alpha_k, beta_k)
E[mastery_k] = alpha_k / (alpha_k + beta_k)
```

冷启动默认 `Beta(1,1)`，完全未知。用户声明“学过”只轻微调整先验，不能代替行为证据。章节掌握由该章证据聚合，但保留知识点级差异。

### 5.3 自适应选题

题库由章节内容生成并带有：知识点、先备关系、难度 `b`、区分度 `a`、响应类型、评分量规、预计耗时和来源块。

当前实现使用 2PL IRT 与贝叶斯不确定性混合排序：

```text
P(correct | theta) = sigmoid(a * (theta - b))
FisherInfo = a^2 * P * (1-P)

item_score =
  4.0 * expected_posterior_variance_reduction
  + 0.55 * fisher_information
  + 0.35 * uncovered_knowledge_bonus
  + 0.20 * user_focus_bonus
  - 0.12 * expected_time_cost
```

早期画像很不准，不能只依赖当前 `theta` 附近的 Fisher 信息，因此加入全局的后验方差减少量和覆盖约束。后期才逐步增加局部区分能力的权重。生产版还应加入题目曝光控制、内容平衡和重复题相似度限制。

### 5.4 多信号证据

一次回答不是只有对/错：

- 答案正确度或量规分；
- 用户自报信心；
- 作答时长；
- 使用提示次数；
- 修改次数与从错到对的路径；
- 开放回答中命中的要点和误解候选；
- 后续能否迁移到不同情境。

提示会降低本次证据权重；低评分置信度的开放回答不更新画像，而是发起澄清。信心与结果使用 Brier 分数累计，区分“不会”与“过度自信的误解”，从而决定后续使用讲解、反例还是信心校准题。

### 5.5 开放回答评分

LLM 只能按预先生成并人工/模型核验的量规评分，返回命中要点、缺失要点、误解证据和评分置信度。低于 `0.78` 或存在多种合理解释时必须追问/弃权，不能把模型的自信当真值。

生产版使用双评分器：一个模型评分，一个更便宜的规则/语义评分器交叉检查；分歧样本进入校准集。每个题型持续统计人与模型一致率、分组误差和置信度可靠性。

### 5.6 停止规则

满足以下任一条件停止：

- 达到最大题数或时间预算；
- 已达到最小题数、重点知识覆盖充分且平均后验不确定性低于阈值；
- 连续题目的预期信息增益低到不值得继续打扰用户。

未覆盖内容继续显示“尚未知”，而不是默认用户不会。

## 6. 个性化课程生成

策略层是确定性的，生成层是受约束的：

- 掌握低或证据不足：`FOUNDATION`，补先备、分步、术语随文解释；
- 中等掌握：`STANDARD`，减少冗余，强调概念联系和典型问题；
- 掌握高：`ADVANCED`，边界条件、反例、迁移和综合任务。

每章生成：

- 原文阅读：经过重建的可读片段和页码，不展示生硬 OCR；
- 章节总结：按用户目标突出不同部分；
- 知识点清单：重要性、当前状态、解释和来源；
- 闪卡：优先覆盖薄弱或易混淆内容；
- 示例与练习：难度匹配后验，不只改变文字长短；
- AI 答疑/RAG：默认限制在当前书和章节，可显式扩大范围。

课程是版本化产物。新证据只使受影响的章节和知识点局部失效并重新生成，避免每次全书重算。

## 7. RAG 设计

索引单元是版面块和语义窗口的组合，检索过程：

1. 查询改写：保留用户原问题，同时生成术语别名；
2. 章节过滤：默认当前章，用户要求时扩大；
3. BM25 + dense embedding 双路召回；
4. cross-encoder/LLM reranker；
5. 来源覆盖与相邻块扩展；
6. 只用检索证据回答，逐条给页码引用；
7. 无充分证据时明确说“本书未找到”，再询问是否使用通用知识。

当前仓库实现了可工作的中文 BM25 基线和稳定接口，密集向量及 reranker 在部署层替换，不影响领域模型。

## 8. 服务拆分与部署路线

### 阶段 A：单机 4090 验证

- Nginx：同域前后端与静态资源；
- FastAPI：业务 API；
- Celery/Dramatiq worker：任务编排；
- MinerU GPU sidecar：文档解析；
- PostgreSQL + pgvector；
- Redis；
- 本地数据盘对象目录，所有持久数据挂载到数据盘。

PUCODING 用于结构化生成、清洗和视觉救援，DeepSeek 可作为文本总结/评分备选。密钥只注入环境变量，不写入镜像、前端或日志。

### 阶段 B：生产扩展

- API 与 GPU worker 分离；
- 页面级任务可重试、幂等；
- 按书籍指纹去重；
- 模型调用缓存、批处理和并发限制；
- 质量低页单独升级模型；
- OpenTelemetry 追踪每页耗时、成本和质量；
- 蓝绿发布，课程版本与提示词版本可回滚。

## 9. 数据与安全

- 上传白名单、文件大小/页数限制、PDF 恶意对象检查；
- 原文件与用户画像按租户隔离；
- 日志不记录全文、回答原文或密钥；
- 画像字段可导出、纠正和删除；
- 模型提供商请求最小化，只发送当前页/当前题所需上下文；
- 诊断不是医学或心理测评，不提供此类结论。

## 10. 验证指标

### 文档质量

- 字符错误率 CER、词错误率 WER；
- 阅读顺序准确率；
- 表格/公式/题号结构 F1；
- 页面质量分与人工评分的校准曲线；
- 低质量页漏检率，优先降低“错误接受”。

### 画像准确度

- 后续保留题预测准确率和 log loss；
- 后验置信区间覆盖；
- LLM 评分与专家评分一致率；
- Brier 信心校准；
- 达到同等预测质量所需题数/时间；
- 用户确认时的修改率，修改高说明画像过度推断。

### 教学效果

- 同难度延迟测试的增益；
- 迁移题表现，而非只看完成率；
- 用户主动跳过/觉得过浅或过难的比例；
- 个性化策略相对固定课程的 A/B 测试。
