# 模块 8：知识追踪、自适应选题与记忆调度融合

## 本轮目标

把此前“已经有自适应外形、算法仍较轻”的部分补实：保留可审计的 Beta
证据计数，同时加入序列化知识追踪；让 CAT 不只追求信息量，也控制章节重复和
难度突跳；把自写的 SM-2 类闪卡规则替换为正式的 FSRS 6 实现。

## 融合结果

### BKT 风格的序列掌握度

- `MasteryPosterior.alpha/beta` 继续保存可解释的成功与失败证据。
- `tracked_mastery` 根据每次回答按猜测率、失误率、评分可靠性和学习转移更新。
- 课程深度和首页掌握估计优先读取 `tracked_mastery`，不再把一次猜对等同于稳定掌握。
- Beta 方差仍负责诊断停止条件，避免序列估计掩盖证据不足。

### 更稳定的 CAT 选题

- IRT 能力值由全局单一估计调整为优先使用当前章节的掌握状态。
- 保留 Fisher 信息量、Beta 预期信息增益、未覆盖知识和用户重点排序。
- 新增难度跳跃惩罚，避免相邻题目突然从过易跳到过难。
- 新增短期章节重复惩罚，避免少量高区分度题把诊断长期锁在同一章。
- 发布题库和恢复的旧题库都强制过滤为选择题，答案密钥仍不进入前端。

### FSRS 6 闪卡调度

- 后端直接依赖 `fsrs` 6.x，不再维护近似 SM-2 的自写间隔规则。
- 持久化 FSRS 的状态、稳定性、难度、上次复习和目标记忆率。
- 旧闪卡记录会在下一次复习时迁移，不会破坏既有学习证据。
- 前端评分后直接显示下次复习时间，并明确说明时间会根据记忆状态动态调整。

## 验证结果

- 后端：101 项测试通过。
- 静态质量：Ruff、MyPy strict 全部通过。
- RAG 独立回归：14 项测试通过。
- 前端：TypeScript 与 Vite 生产构建通过。
- 430 × 932 手机视口：无横向溢出；FSRS 提示、闪卡和课程标签未重叠。
- 真实 UI 流程：四步背景选择、五道选择题、画像确认、薄弱章课程生成、闪卡翻面和
  FSRS 复习提交全部成功。
- 测试会话中，章节掌握估计形成约 15%–66% 的差异；15% 的薄弱章被编排为
  “基础支架”课程；闪卡选择“记得”后安排在 2 天后复习。
- 本轮代码已发布到 4090 数据盘目录；冷重启后 `/api/health` 和 RAG 健康检查均通过。
- 生产生物教材保持 125 页、6 章、只发布一本；诊断题库为 18/18 选择题，解释题为 0。

## 边界

本轮没有引入深度知识追踪模型训练。当前 BKT 参数使用保守默认值，待累积真实匿名
答题数据后再离线校准。IRT 题目参数目前也仍由生成阶段提供先验，不能把它当成已经
经过大规模考生数据标定的正式量表。
