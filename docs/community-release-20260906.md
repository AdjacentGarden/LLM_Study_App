# 社区内测版：实现与验证记录

日期：2026-09-06。部署位置：4090，`/data1/zhenghang/adaptive-book-ocr/app`。

## 使用入口

底部导航：学习、书架、社区、答疑、我的。

- 社区可按书籍、闪卡、笔记筛选、搜索、预览、免费领取。
- 书架 → 分享书架内容：发布现有已解析教材，或选择自己已生成的课程闪卡。
- 书架 → 闪卡与笔记：写私人笔记、阅读社区收藏、翻阅共享闪卡。
- 笔记保存与公开分享分开；发布需要确认传播权限。
- 分享者可以撤回展示；已经领取的内容快照保留。
- 书架管理仅移出引用，提供当次撤销，不删除 PDF、OCR、索引或学习记录。
- 收起学习资料采用软归档，提供当次撤销；社区资料再次领取会恢复同一个副本。

## 数据与去重

新增 SQLite 数据库 `data/state/community.sqlite3`，不改写既有教材和学习数据库。

1. PDF 的 SHA-256 内容指纹来自已有上传记录，不依赖文件名。
2. 解析文本使用完整索引分块正文计算规范化指纹；短于 200 字符的文本不用于合并。
3. 相同文件或规范化正文映射到同一个 canonical book ID；同名但指纹不同仅提示核对版本，不自动合并。
4. 每个访客的书架有唯一 `(owner, canonical)` 约束；领取使用 SQLite `BEGIN IMMEDIATE` 事务。
5. 领取书籍只新增云端引用，复用原书章节与 RAG 索引，不复制分享者画像、诊断答案、课程版本或学习记录。
6. 笔记与闪卡领取创建独立内容快照。闪卡公开字段只有题面、答案、教材页码；修改原稿不覆盖已分享或领取的快照。

指纹不是跨版本语义鉴定器。重新 OCR 导致文本变化的文件可能无法自动判为同书；不同版本不会仅凭相似书名自动合并。

## 身份与边界

- 服务端随机生成访客凭证，使用 HttpOnly / SameSite=Lax Cookie，数据库只存凭证哈希。
- 私人资料读写、发布、撤回均验证访客归属；跨来源写请求被拒绝。
- 旧版学习会话沿用不可预测的会话 ID，在第一次用于分享时绑定访客；没有将旧项目整体改造为账号权限系统。
- 当前适用于私有网络内测，浏览器清除 Cookie 或换设备会形成新的访客身份。不是跨设备账号同步方案。
- 此次提供现有已解析书架内容的发布与领取，没有新增面向公众的任意 PDF 上传流程。
- 公开商业上线仍需统一账号认证、旧接口权限迁移、HTTPS、配额限流、举报审核、版权处理及账号恢复。
- “免费加入”是加入云端书架，不是把 PDF 或模型索引下载到手机离线存储。

## 验证结果

### 自动化

- 后端：220 项通过，其中社区专项 18 项。
- 前端既有回归：22 项通过；TypeScript 与 Vite 构建通过。
- 后端 41 个源码文件 mypy strict 通过，Ruff 检查通过。
- 社区专项覆盖默认 5+5、访客隔离、相同 PDF/文本去重、同名不同版本提醒、24 路并发领取幂等、笔记字段校验、越权编辑拒绝、分享撤回、快照隔离、归档恢复、卡片子集校验、安全字段、分页搜索及跨来源写保护。

### 4090 真实接口

- 社区 5 本书逐本领取并检查封面及章节，全部通过；领取往返耗时 85–115 ms（本次实测，不代表性能保证）。
- 每本额外并发重复领取 6 次，均返回已拥有，书架没有重复项。
- A 访客加入全部 5 本后有 10 本，B 访客仍是初始 5 本。
- 笔记完整生命周期通过；测试帖子已撤回，测试副本已归档。
- 真实 C++ 课程 11 张闪卡发布并由独立访客领取，内容逐字段一致，无画像或诊断字段。
- 高等数学问答“导数的几何意义”返回 supported，引用 PDF 第 95 页；检索约 155 ms，生成约 15.5 s，证据语义校验通过。
- 实际服务器 10 个素材都有 PDF 指纹与解析文本指纹，映射到 10 本不同的书。

### 手机模拟器实际操作

- 第五个导航项、社区封面列表、笔记/闪卡筛选、详情弹窗和独立滚动。
- 高等数学加入后书架由 5 变 6，打开后是该书独立的初始诊断界面。
- 私人笔记创建、保存、分享确认、社区展示、撤回、原稿归档。
- 真实 C++ 闪卡分享预览、发布、翻面、下一张重置题面、上一张、撤回。
- 高等数学移出、撤销恢复、再次移出，最终书架为 5 本。
- 当前 C++ 原有学习进度可正常恢复，没有覆盖为领取者或其他访客的数据。
