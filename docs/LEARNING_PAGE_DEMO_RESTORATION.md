# 学习页：恢复 Demo 流程并接入真实功能

2026-09-27。此任务在 P0–P5 移植之后追加，依据用户要求，以原 Demo 学习页的逻辑和功能为基础修改，再加入当前项目已有能力。由 GPT-6 Sol / max 子代理实施，主代理负责集成、代码复核与浏览器验收。入口为 `/?ui=next`。

## 真实数据与边界

- 新增 `GET /api/interviews/{session_id}/study-workspace`、`PATCH .../study-tasks/{task_id}` 和 `PATCH .../mistakes/{mistake_id}`。任务及错题回访状态保存在 `APP_DATA_DIR/state/study_workspace.sqlite3`；会话归属、书架拥有关系和写入 Origin 都受校验。
- 计划按真实可学习节点生成阅读、练习和闪卡任务。阅读完成是明确的自我标记；练习和闪卡可依据当前最新课程版本的真实活动完成。旧版本作答不会使新版新题自动完成。手工撤销不会删除已存在的真实学习活动。
- 错题来自真实练习中低于 65% 的服务端评分；历史题保留课程 ID 和版本。重试使用现有幂等事件 ID；响应丢失后再次提交不会重复计分。错因及“自报已掌握”与原始评分分开保存。
- 新层级从可信 OCR 标题及原文证据提取，覆盖同页多小节边界。没有可靠层级的旧教材继续显示平铺章节；不会把知识点标题伪装成原书小节。无可核验知识点的小节可读原文，但不能生成个人课程。
- 结构升级后，仅有真实历史记录的父章任务作为“历史整章”保留。原来的课程、练习事件、诊断题库指纹兼容路径保留。
- ICS 是用户选择开始日期后的全天日程文件；不包含外部日历双向同步，也不将建议用时显示为实际学习时长。目录编辑、课程 PDF 导出和 Android 仍不属于本任务。

## 2026-09-28：章节内恢复 Demo 的独立页面

按照后续确认，教材第一章在目录和页面中作为普通章节呈现，不再出现“补充学习”、缺少原文等特殊标记；原有导入章节标题中的提示后缀也在界面层清理，新导入数据不再写入后缀。第一章仍使用已有的章节讲解、三道练习和六张闪卡。由于 PDF 中没有该章正文，页面不生成虚假的“查看原文”链接，简答题只展示参考答案供学习者自行对照。其练习、错因、掌握标记和闪卡反馈单独保存在当前浏览器的账号隔离空间，不写入正式诊断分数或 FSRS 日程。

章节工具卡现分别打开独立的分页讲解、逐题作业诊断、叠放翻面闪卡和错题集。讲解支持左右滑动、键盘切页、图文、原文入口和完成本节；作业按实际题量展示判断／选择／简答及结果页；闪卡提供“还不熟／记住了”的二元反馈，有源卡对应现有 FSRS 的 `again/good`。正式课程的作业由服务端评分，作业题公开响应只增加原文引用而不公开答案；正式错题仍使用服务端原课程版本重做、前后答案对照、错因与掌握状态。课程更新、教材答疑、Studio 和疑问回访在讲解页保留。

当前实现入口为 `NextDemoChapterScreen.tsx`，其样式为 `styles/next/demo-chapter.css`，路由接入 `AppRoot.tsx`。隔离教材的 Playwright 检查涵盖第一章完整三题结果、作业／闪卡／错题直达、第二章原文配图和服务端作答／FSRS 记录；原学习计划、正式错题重做与目录位置测试继续通过。

## 2026-09-28：移入 Demo 讲解内容，原文页直接手写

- 新增 `GET /api/books/{book_id}/teaching-lessons/{chapter_id}`。它从已导入的 Demo `teaching.json` 读取导读、学习目标、讲解块与配图。13 节带 PDF 原文的讲解继续经过原文页引文核验；第一章 2 节直接使用已有的讲解块，在目录、讲解、学习计划摘要、任务详情与日历导出中均按普通章节呈现。接口要求当前账号拥有教材，并核对导入包、登记指纹与当前 PDF 文件。第六、七章没有 Demo 讲解包，保留现有个人课程讲解。
- 章节阅读优先显示 Demo 的导读、目标与四段讲解，再接当前项目独有的个人化例题、知识要点、选段图解／短片、教材答疑和学习记录。作业诊断、闪卡复习、错题集继续沿用上一阶段恢复的 Demo 页面与交互，正式课程的服务端评分及 FSRS 记录不变。
- 原文页现在将透明手写画布叠在真实 PDF 页图上，提供阅读／移动、手写、按笔画擦除、撤销／重做、三种笔色、手指书写开关和缩放。笔迹使用原 Studio 的向量笔画格式，按账号、教材、PDF 指纹和页码独立保存；草稿先存浏览器会话，随后自动保存，也可手动保存。翻页或返回讲解时先等待当前页保存，失败时留在原页并保留草稿。
- 新增 `GET /api/studio/source-page` 来取得该页笔记身份与已保存笔迹。写入仍走现有 Studio 笔记接口，复用版本冲突校验、笔迹识别和 AI 整理。识别时分别提供独立笔迹图及笔迹叠原文的定位图，避免将教材印刷文字误作用户笔记；整理版和原始笔迹分开保存。原 PDF 文件不被改写。第一章没有对应 PDF 页，仍可创建普通空白手写笔记。

后端隔离测试覆盖导读／目标／配图、原文引文、账号归属、笔迹幂等保存、跨页隔离、PDF 变更和合成图像。`frontend/e2e/next-source-ink.spec.ts` 在独立的生物教材验收运行目录上，检查第一章与第二章阅读、页图和画布对齐、手写保存、翻页恢复、返回自动保存。此浏览器测试以既有验收课程 JSON 固定个人课程响应，避免依赖外部闪卡审校模型；讲解接口、PDF 和笔记读写均调用真实本地后端。
