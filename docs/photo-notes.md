# 照片笔记

在学习笔记页点击“拍照导入”，或在笔记类型选择页选择“拍照导入手写笔记”。支持相机和相册的单页图片。

导入会先保存原图，再生成用于识别的 JPEG。原图不被识别结果覆盖。点击“提取并整理”后，DeepSeek Flash 分别生成忠实转写与整理笔记，用户可以对照原图编辑，并保存为照片笔记或追加到同课程的已有笔记。照片、机器提取原文和编辑后的正文分别保留；照片原稿可在笔记详情中打开。

识别失败或网络中断不会丢失原图。重新打开照片笔记可查询原任务；只有已经确认失败的任务允许重新生成。追加使用笔记版本校验，目标笔记在生成期间更新时会保留草稿并提示冲突，避免覆盖新内容。追加与临时草稿删除在同一 SQLite 事务中完成。

当前照片 AI 流程要求登录、联网，并关联已上传教材。原图上限 25 MB，识别副本上限 8 MB、最长边 4096 像素。模型只整理照片内容，不自动补充教材知识或纠正作者观点；模糊字、数字和公式应在保存前核对。

## 后端

`POST /api/studio/photo-notes` 接收教材 ID、请求 ID、Base64 图片、图片 SHA-256 和生成授权。服务检查教材访问权限、图片真实格式和尺寸，并通过现有 Studio 笔记工作队列执行 `photo_note` 任务。任务结果由既有 `/api/studio/jobs` 接口查询。

配置沿用已有 DeepSeek 凭据与网络出口，模型为 `deepseek-flash`。接口能力字段为 `photo_notes`。模型请求不自动重试；图片布局先整体读取，较大图片附上有重叠的细节图，保留小字和跨区域关系。

## 验证

后端回归：`pytest tests/test_photo_notes.py tests/test_studio_voice_note.py tests/test_accounts.py tests/test_private_forwarding.py`。

原生单测包含图片规范化、旧笔记兼容、原图持久化、追加事务、冲突、账号／课程隔离、文件共享引用和请求恢复。UI 测试使用 `PhotoNoteUITests`，验证系统相册选择、预览编辑、保存、重启恢复和追加。

`frontend/scripts/photo-note-test-server.py` 是仅监听回环地址的 UI 回归服务，执行实际 Studio 队列并使用测试模型适配器。Debug 构建在隔离的 `--fixture` 数据库中可用 `--fixture-photo-server http://127.0.0.1:19286` 注入测试网络出口；正式构建不会加载该入口。真实 DeepSeek 调用应另外验证，模拟器无法替代真机相机和自然手写样本验收。
