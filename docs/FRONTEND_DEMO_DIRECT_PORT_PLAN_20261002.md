## 1. 目标与实施边界

本计划中的“最新 Demo”指 P0 于本轮开始时保存的来源工作树快照。来源在执行期间新增的 UI、图标和示例课程未纳入本轮已验收实现，具体差异见验收记录。

默认入口直接运行最新 Demo 的 App、页面、布局、样式、导航、抽屉和动效。后端适配页面需要的课程、资料、课时、问答、笔记、复习和报告契约。前端允许修改数据仓库、身份接入、任务状态和实际结果绑定；不再重新设计一套 DemoPort 页面。

- 同步最新 Demo 的课程容器、多资料、首次引导、课程设置、课程详情、统一笔记、语音笔记、原文批注与圈选问答。
- 保留目标仓库的账号注册登录、好友私信、社区分享领取、学习画像、个性化课程、评分、FSRS、疑问回访和 Studio 能力，通过 Demo 控件和补充入口接入。
- 将演示逐字稿、整理文本、报告数字、任务分数、积分和导出成功提示接成真实数据或真实任务结果。
- Web 为本轮验收平台，覆盖手机、平板和桌面；保留原生平台适配源码，不新增 Android 发布任务。
- 使用现有服务和配置。外部服务不可用时返回真实能力状态和错误，不伪造完成、不用固定教材内容替代新上传资料。
- 不部署、不发布、不提交 Git、不删除真实数据库或学习记录。
- 不修改来源仓库，不复制 `.env*`、依赖目录、构建目录、缓存、录制产物或模型权重。已有前端示例教材的业务数据仅可作为明确的测试/演示资源使用，不能成为生产账号默认数据。

2026-09-27 至 2026-09-29 的历史移植和验收记录保留。本计划覆盖最新 Demo 同步与直接运行方向；历史的单 PDF 首版限制不能代替本轮的多资料范围。

## 4. 实施阶段与产物

### P0：冻结基线和契约

1. 保存来源文件清单/哈希与目标修改基线。
2. 阅读现有账号所有权、Origin 校验、OCR、课程、Studio、社区和学习记录服务，选择可复用服务。
3. 将 `BookCourseRepository` 从具体 DemoRepository 类改成可实现的公开接口；确定兼容 API 的路由、字段、错误及任务状态。
4. 明确三个概念：课程容器 CourseSpace、原始资料 Source/Resource、章节课时 Lesson；已有个性化章节学习包不与课程容器混用。

产物：兼容契约说明、文件基线；不得以设计文档代替后续实现。

### P1：同步最新原前端并切换真实数据边界

1. 同步 App、screens、components、features、layouts、motion、styles、类型及需要的品牌/字体资产。复用后端教材资产地址，避免依赖不存在的静态路径。
2. 默认入口挂载最新 Demo App 与必要的账号 Provider。保留设备预览入口、手机/平板响应式、返回/抽屉状态与 reduced-motion。
3. 同步所需依赖及锁文件，使用来源已解析的版本，不使用新的 latest 依赖。
4. 接通四处数据边界：bookcourseApi、课程仓库、笔记仓库、积分仓库。IndexedDB/localStorage 可作为账号隔离缓存和临时草稿，不作为唯一已保存业务结果；避免导入示例笔记或 local_user 到真实账号。
5. 写操作收到后端确认后才显示已保存或成功；加载和身份切换不得串书、串账号。

产物：原 Demo 页面作为默认 UI；不再通过旧包装页面替代原导航树。

### P2：课程、偏好与多格式资料后端

1. 增加按账号保存的课程容器、关联资料、偏好、活动课程和草稿接口。原有个人教材自动纳入可选择资料，不修改原始教材和学习档案。
2. 支持 PDF、常见图片、DOCX、PPTX、XLSX、TXT、MD、CSV 的原文件保存和文本/页/幻灯片/工作表结构提取；采用已有依赖和标准库优先。格式不支持的细分能力应清晰反馈，不能展示假整理结果。
3. 提供上传初始化/保存/解析任务/扫描结果，统一状态和 0–100 进度。任务失败可重试，刷新可恢复，同一操作重试不生成重复资料。
4. 提供目录层级、印刷页映射、目录证据、编辑、重建、确认及版本更新。人工编辑不伪造 AI 置信度；引用仍能定位真实资料。
5. 原文页、文本和文件访问始终核实账号所有权，非 PDF 资料保留其来源定位语义。

产物：真实创建课程、添加多份资料、解析与确认目录的完整流程。

### P3：课时、问答、作业、复习与计划兼容

1. 后端返回 Demo 的 Lesson、LessonBlock、ApiChapter、ApiChunk、ApiAsset、Flashcard、Quiz 等契约；已有课程包、导入讲解、RAG 索引和素材可复用。
2. 课程设置后可直接阅读资料/基础课时，不强制走旧的完整诊断流程。个性化需要的声明偏好与真实诊断证据分别处理，不自动伪造小测回答。
3. 适配课时构建任务、素材任务、状态查询和失败恢复；不阻塞 HTTP 请求等待不可控长任务。
4. 扩展问答的课程/多资料/章节范围、历史、圈选图像和区域。仅检索账号有权且属于所选课程的资料；引用带来源身份、页码、文本块及素材。模型请求由后端执行，浏览器不携带模型 Key。
5. 使用现有服务端评分生成作业提交与诊断结果，记录真实错题；保留幂等事件 ID、课程版本和证据。正确答案与解析按教学流程返回，不能用演示本地判分代替。
6. 闪卡绑定 FSRS 和到期状态；计划/错题聚合到课程资料，任务完成与真实掌握证据保持不同含义，不保存固定 88 分。
7. 保留账号、好友、社区、画像、疑问回访及 Studio 的现有可用入口和权限。

产物：读课、作答、诊断、复习、计划和问答的真实闭环。

### P4：新版笔记、语音、积分、报告与导出

1. 统一文字/手写/语音笔记响应，支持课程/资料/章节/页锚点、批注位置、跨页笔迹、荧光笔、录音、逐字稿、原始版本、整理版本和对话。
2. 复用 Studio 音频上传、识别、分析、任务和整理版本能力；适配新版笔迹字段和坐标，保留原始录音与笔迹。移除 demoVoiceTranscript、demoOrganizedVoiceText 等正式流程固定输出。
3. 圈选问答实际上传选择的图像/区域和上下文，无法使用视觉模型时给出真实能力状态，不声称看到了未处理的图像。
4. 积分余额、预留、完成和失败退还在服务端保存且幂等，关联真实问答/媒体任务，不由浏览器自行决定扣费金额。默认赠送策略明确且只初始化一次。
5. 章节报告由作答、用时、复习与知识证据聚合，空记录显示空态，不展示固定 82%、24 分、2 题。
6. 根据所选模块导出实际课程/笔记/引用/复习内容，产生有效 PDF 下载文件，失败时不提示成功。保留原导出预览页面布局。

产物：笔记和导出可刷新恢复；报告与积分来自真实服务端数据。

### P5：集成验收、清理和交付记录

1. 前端 TypeScript 与生产构建通过；运行合适的前端单元测试。
2. 后端新增契约、权限、重试、版本、资料解析、笔记和积分测试通过；运行现有相关账号、社区、评分/复习、原文、Studio 和学习工作区回归。

4. 核验刷新、两账号切换、跨资料引用、服务重启、重复提交、失败重试、外部能力未配置时的反馈；不访问或清空用户真实数据。
