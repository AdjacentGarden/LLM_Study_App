# 注册与登录体验优化 · 2026-09-07

## 范围

基于主干 `a6ba9bf`（QQ SMTP 配置更新），只调整前端账号体验。部署同步前端源码与构建产物，未重启后端、修改 SMTP、模型配置或既有用户资料。演示测试只使用公共 `.test` 账号。

## 界面与交互

- 淡紫与暖白的品牌层次，书本装饰、统一输入框、分段切换和轻量进入动画；尊重减少动态效果设置。
- 两步注册：邮箱/验证码 → 昵称/学习偏好。第二步更紧凑，主操作固定底部，返回保留偏好。
- 第一页只检查是否填齐，不标记邮箱已经验证；实际验证码与注册资料一起交由后端校验。
- 验证码支持数字输入与系统自动填充、发送后聚焦、基于绝对时间的重发与过期判断。
- 修改邮箱或切换注册/登录会清空旧挑战；重复点击当前模式不清空；重发失败不继续保留旧挑战。
- 发送/提交时防重复操作；校验失败回到邮箱步骤，仍保留偏好；错误和过期提示位于底部可见区。
- 演示账号入口折叠展示，明确区分公共测试验证码和真实邮件。
