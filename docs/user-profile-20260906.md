# 个人资料内测版

- 删除“我的学习”页标题右侧的头像，仅保留“我的学习档案”左侧头像。
- 保留的头像为按钮，进入独立“个人资料”页面，没有增加额外导航或菜单入口。
- 设置项：头像上传、恢复默认、昵称（1–32 字符）、可选年龄（1–120 整数）、简介（最多 160 字符）。
- 点击保存后统一写入 4090 数据盘 `data/state/community.sqlite3` 的 `user_profiles` 表。取消不保存；空年龄存为 NULL。
- 新增 `/api/user/profile` GET/POST 和私有头像 GET `/api/user/profile/avatar`。
- 访客由既有 HttpOnly Cookie 区分；服务端按 owner 读取，客户端不能提交 owner。
- 头像最大 2 MB / 1600 万像素，允许静态 JPEG、PNG、WebP；后端解码并裁剪成 256×256 JPEG，清除 EXIF 等元数据。照片不是外部 URL，不发送到第三方模型服务。
- 保存带 revision，过期版本返回 409，不静默覆盖另一页面的新资料。
- 使用原有 4090 服务，无本机后端；备份在 `release-backups/user-profile-20260906`。

验证：后端专项测试覆盖持久化、跨客户端 Cookie 回显、其他访客隔离、头像重新编码、默认重置、文本更新保留头像、非法年龄/图片/字段、并发冲突及跨来源写保护；既有回归与构建通过。
真实 4090 接口已测试上传、读取、恢复头像、资料保存和用户隔离。真实模拟器已测试唯一头像入口、昵称/年龄/简介保存、刷新回显、非法年龄禁用、取消不写入和恢复测试前资料。
系统文件选择窗口不能由当前自动化工具完整控制，因此未声称完成从本地文件选择到保存的全链路 GUI 上传测试；头像接口使用实际图片在 4090 验证通过。

边界：目前仍是浏览器访客身份，不提供账号登录、跨设备同步或 Cookie 丢失后的找回。这里的年龄、简介不公开到社区，不改变当前学习画像与既有诊断记录。学习提醒和字体大小仍沿用原有本机设置，此次未迁移。
