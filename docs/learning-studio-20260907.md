## 真实性与能力边界

真实测试在网页画布通过指针事件写入 DNA 的 4 条笔画，模型识别为 `D N A`，用户确认步骤归一为 `DNA` 后，返回带教材第 49、50 页依据的补充。保存整理版后，服务器上的原始 4 条笔画保持不变。该端到端测试约 59 秒（包括页面操作及轮询），不代表一般时延保证。

这是一个简单拉丁字母手写样本。**未完成真实 Apple Pencil 设备、复杂中文连笔、混合公式/图表的大规模识别验收**。网页画布不是 PencilKit；移动采用明确工具模式，未实现完整的原生手势/防手掌误触。当前保留原笔迹并用正常字体呈现整理版，未实现个人字体克隆、智能套索、跨页无限画布、逐条建议接受或自动更新掌握度。

图解标签以独立 HTML 文本列出，不要求生图模型绘制中文。视频固定请求 6 秒，文件解码与时长检查限制在 15 秒内；视觉复核采样 0–5 秒帧，不是逐帧知识正确性证明。未实现确定性科学动画、语音配音或动态标签追踪。

资料定位目前覆盖生成课程的原文摘录；没有改造扫描 PDF 的像素坐标选择层。工具面板支持手动填入教材片段，并交给教材检索和复核，不将用户输入直接认定为原书逐字引文。讲解深度为用户选定，不自动读取掌握画像，避免假装已经掌握其困难点。

## 后端

复用 `community.sqlite3` 与既有账号/书架鉴权，增加：

- `studio_notes`：原始笔画、教材锚点、标题、乐观锁 revision。
- `studio_jobs`：请求指纹、幂等键、状态、供应商任务 ID、结果、保守媒体额度预留。
- `studio_note_editions`：用户接受/撤回整理版的记录；不覆盖手写。

素材在 `APP_DATA_DIR/learning-studio/`；仅由同账号且仍拥有教材的鉴权路由返回，响应 `private, no-store`，不加入公开静态目录。

任务队列由一个独立线程串行处理，部署当前为单 Uvicorn 进程。视频轮询不会每次都重新提交。不要直接多进程启动此工作队列；横向扩容前必须加入跨进程租约和任务锁。

重启时：`planning` 回到队列；`submitting` 转为 `uncertain`，不重发可能已收费的请求；`polling` 保留 task_id 继续查询；`reviewing` 使用已落盘素材复核。`uncertain` 需要管理员与供应商核对，尚无自动账单对账。

每人滚动 24 小时最多 20 次任务、全服务最多 100 次、最多 12 个在途任务。默认媒体滚动 24 小时总预留额为 5 元，image-01 0.025 元、6 秒 Hailuo-2.3 2 元。预留统计不是供应商真实扣款记录；失败也保守占用，避免自动重试超支。文字与视觉理解 Token 费用不包含在该人民币预留额中，受任务数量限制。

所有笔记识别先忠实转写，不参考教材把错误观点提前改正确；补全阶段要求用户确认文字。建议的原句必须出现在确认文本中，证据必须能在给定页逐字匹配；最后仍需要模型复核和用户判断，不宣称绝对准确。

## API

所有路径位于 `/api/studio`，沿用 HttpOnly 身份与同源写入检查：

| 路径 | 用途 |
| --- | --- |
| GET `/capabilities` | 可用能力、媒体暂停提示、账号隔离草稿作用域 |
| POST `/media` | 提交图像/视频任务，显式 consent 与 request_id |
| GET `/jobs?book_id=…` | 个人任务历史 |
| GET `/jobs/{id}` | 单个任务状态 |
| GET `/jobs/{id}/asset` | 已成功且通过复核的私有素材 |
| GET/POST `/notes` | 列出/保存手写笔记 |
| GET `/notes/{id}` | 原笔迹与已接受整理版 |
| POST `/notes/{id}/analyze` | recognize / improve，绑定笔记 revision |
| POST `/notes/{id}/edition` | 接受/撤回整理版 |

## 部署配置（不包含密钥）

服务管理脚本额外读取数据盘 `secrets/learning-studio.env`，权限 0600。配置项：

```dotenv
MINIMAX_API_KEY=<仅服务器保存>
MINIMAX_BASE_URL=https://api.minimaxi.com
STUDIO_LLM_PROVIDER=pucoding
STUDIO_NOTE_LLM_PROVIDER=pucoding
STUDIO_LLM_MODEL=MiniMax-M3
STUDIO_MEDIA_DAILY_CNY=5
STUDIO_FFMPEG=<数据盘上的 ffmpeg 可执行文件>
STUDIO_MEDIA_PAUSED_REASON=<可选：暂停原因；非空即暂停媒体请求>
```

本次从 PyPI 安装独立的 `imageio-ffmpeg==0.6.0` 到数据盘 `studio-runtime`，使用其 ffmpeg 7.0.2 二进制检查视频，不更改现有 OCR 环境。

**首次充值后验证（历史）**：仅实际提交一张 image-01 图片，没有视频请求，没有批量重试。第一次任务在规划阶段失败（未保留详细原因），人工诊断重跑同一任务的规划后通过，并只提交了一次生图。对应默认媒体预留 0.025 元；不等于已核实的实际扣款，PUCODING 规划/复核的 Token 费用另计。真实图片被内容复核拦截后停止当轮模型测试。

首次增强的通用提示词保留复合名词中心词与真实对象类别，并新增私有复核原因记录；后续已用新样本继续验证，发现仅靠提示词不够，因此增加内容分流、逐项审核和有界文字修订。具体成功与失败样本见最新质量记录，不宣称已彻底解决生成模型的语义偏差。

- `frontend/e2e/studio-media-playback.spec.ts` 使用既有测试身份和任务只读检查展示、刷新与素材权限；仅有成功视频时才验证播放/跳播，不提交生成请求。通过 `STUDIO_MEDIA_RESULTS` 指向私有结果目录启用。
- 视觉讲解测试中模拟的供应商响应只证明流程行为，不能证明真实媒体质量。

发布前备份位于数据盘 `release-backups/learning-studio-20260907/`（旧 backend/src、frontend/dist、服务管理脚本、SQLite 在线备份）。回滚程序时保留新增数据库表与素材；不要自动恢复旧数据库，否则会丢失发布后的真实学习记录。

本地临时草稿位于账号作用域隔离的 sessionStorage，服务器保存成功后清理；未同步时关闭会被阻止并显示重试入口，版本冲突可另存为新笔记。它不是完整离线同步系统；关闭整个浏览器会丢失仍未上传的 sessionStorage 草稿，用户应先确认保存成功。
