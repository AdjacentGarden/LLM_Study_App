# 视觉教学质量迭代（2026-09-07）

## 本轮原则

服务器仍为 4090 数据盘，未启动本地后端，未提交 Git。保留 5 元滚动 24 小时媒体预留上限；没有清零失败任务额度，也没有自动重试可能已收费的请求。本轮真实 MiniMax 图片最多 4 张，短片最多 1 条 6 秒；文字/视觉审查的 Token 费用另计，不等于媒体预留或实际账单。

不将“请求成功”“画面好看”或单个模型的通过结论等同于教学准确性。真实图片必须检查对象类别、关系、题外文字、学习价值；视频还必须检查时间一致性。人工检查测试样本，程序测试覆盖权限、缓存与失败关闭。

## 实测发现与修正

1. 静态图规划混入动画指令：上下文没有区分输出类型。已分开静态画面和 6 秒运动规划。
2. 画面省略了讲解声称呈现的内容：引入 `visual_scope`，界面显示“这次看懂”，只声称图实际能解释的子问题。
3. 自由生图不适合精确结构：DNA 样本近乎空白，验电器连接错误。生物/化学微观结构、器械连接、机制、算法和数量关系分流到确定性关系图。关系图明确不是实物结构图。
4. 关系三元组可能语义不完整：生成前逐条审核，将“主语—关系—宾语”拼成完整句。规划最多一次文字修订，再次审核仍不通过就结束，不提交媒体请求。
5. 画面正确但说明承诺过多：仅对实体正确、无题外文字的静态插画允许一次说明修订，保留原素材。修订必须仍解释选段中的有用子问题，再核对教材并重新视觉审核；不能通过该路径挽救错误实体、乱码或畸变视频。

## 新管线

- LLM 规划 `visual_mode`、明确讲解范围、可见检查点与教材关系。
- 独立文字审核；必要时最多一次文字修订并复核。
- `diagram`：仅接受有长度边界的文字三元组，Pillow + CJK 字体固定排版，不执行模型代码或 SVG，不调用 MiniMax。显示“教材关系图”，不能误当成分子结构或受力示意图。
- `illustration`：MiniMax image-01，仅一张图；不自动重绘。
- 视频：对于同账号、同书、同选段/页码/讲解目标/深度的已通过插画，可通过 Base64 首帧复用，避免重新创作整个场景；不复用其他人的图片或关系图。首帧输入遵循 [MiniMax 图生视频接口](https://platform.minimaxi.com/docs/api-reference/video-generation-i2v)。
- 独立视觉审核不读取生成提示词，先描述实际画面，再核对教材和检查点。任何一项不通过，素材继续隐藏。审核理由私有留存，不把内部诊断字段显示给普通用户。

## 费用与能力边界

文字修订也是模型调用，可能增加等待时间与 Token 费用；每阶段次数有界，不采用无限重试。任务队列仍是单进程串行工作线程，生成/规划期间其他任务会排队。

关系图消除了自由绘制拓扑、乱码及不稳定排版的问题，但源文本理解和关系提炼仍可能出错，需继续核对教材。它不等价于经过验证的数学绘图引擎、分子建模软件或真实实验。

视频只采样逐秒帧审核，不保证帧间所有细节绝对正确；尚不支持配音或精确科学运动。不能把有限样本通过宣称为任意教材都无误。
