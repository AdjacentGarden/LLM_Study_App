# 前端学习工作室改版 · 2026-09-04

## 范围

仅修改现有 React 前端，保留接口、书籍、用户画像、闪卡审校与复习逻辑。
按照界面设计技能的可读性、工作界面优先和状态反馈规范，沿用既有图片资产和组件，
不增加运行时依赖，不转移托管平台。部署仍在 4090 数据盘。

## 体验调整

- 首页直接展示按真实诊断结果推荐的下一课，课程与闪卡入口放在同一重点区域。
- 用深色重点卡、浅色章节卡和轻量书籍条区分层级；不虚构进度、连续学习天数或掌握率。
- 底部导航统一线性图标与滑动高亮；支持原生 View Transition 的浏览器增加页面交接动画。
- 章节标签支持点击、左右方向键、Home/End，并保留正确 ARIA 关联与键盘焦点。
- 闪卡有层叠卡片效果、进度条、正反面样式、横向滑动、键盘方向键和前后按钮。
  纵向手势不换卡；拖动不触发点按翻面；首尾边界禁用；不因滑动而记录“掌握”。
- 翻面后的答案使用正常正文字号和完整自然高度。隐藏面不再强行撑高题面。
- 记忆反馈按钮展示清晰语义，仍调用原评分接口；手动换卡清除上一张的反馈提示。
- 答疑增加已发送问题气泡、检索中的骨架状态、完整答案和可折叠原文依据。
  支持 Enter 发送、Shift+Enter 换行；输入法组词时不误发；请求期间禁止重复发送。
- 设置页区分学习统计与偏好，时间字段明确为本机保存的设置，不声称已接通系统通知。
- 练习草稿在同章标签切换后保留；更换练习题时仍遵循既有清空规则。
- 所有动画遵循 prefers-reduced-motion，未支持 View Transition 的环境正常即时导航。

## 实测

测试使用本地 5174 前端预览，API 经 SSH 隧道连接 4090；未启动本地后端。
独立于用户 18100 页面的测试会话完成以下操作：

- 目标、重点章节、背景、时间选择 → 12 道诊断题 → 画像确认 → 个性化首页。
- 真实课程生成与五个章节标签映射；方向键切换以及 End 到练习页。
- 左拖到下一张、右拖返回、不误翻面；键盘换卡；末张按钮禁用。
- 点按翻面、完整答案与引用页码显示；一次真实复习评分保存并进入下一张。
- 答疑通过 Enter 发送“DNA 半保留复制是什么意思？”，获得真实教材回答及 3 条依据。
- 展开引用、Shift+Enter 换行，确认编辑草稿不改变已发送的问题。
- 时间设置与 100%/120% 字号；检查后恢复测试偏好。
- 320×740、390×844 与默认手机外框视图；检查主要容器无横向溢出。
- 浏览器未记录新运行错误或警告。生产构建成功，8 项前端单元测试通过。

这是浏览器模拟环境的验证，不等于安卓/iOS 实机与系统键盘的完整兼容认证。
本次未改动原有原文提取、知识点生成或练习题生成质量逻辑。
