# 书架、社区与选书答疑验收（2026-09-06）

## 产品变化

- 书架去掉每本书的彩色底板。固定比例的封面区、双列间距、书名与元数据对齐、底部细分隔线共同维持分组。正在阅读的标记移到文字区，不遮盖封面。
- 所有书架封面统一左倾 3°，悬停回正；键盘聚焦同样提供反馈，触屏直接轻触预览。不再使用奇偶列反向旋转。
- 社区书籍列表采用轻量分隔行，完整显示封面（contain，不裁切）。统一左倾 3°，默认缩放 0.94，悬停 1.02；布局不随动画重新排版。减弱动态效果设置关闭过渡。
- 社区浏览与发布分类仅保留书籍、笔记。保留服务器旧闪卡数据、个人收藏和好友私信分享功能，不做数据删除。私人闪卡预览不再提供公开社区发布入口。
- 答疑顶部可以从当前书架选择教材；首次默认当前学习教材。答疑选书与学习选书分离，不更改学习会话、进度或书架。推荐问题重新读取所选书章节，异步响应有取消保护。换书清除旧问答结果，空书架禁用发送。
- 当前仍是单书检索，不假称已经支持跨全书综合问答。跨书检索需要后续增加书籍级召回、跨书证据排序、逐条书名与版本引用，以及相互矛盾的资料处理。

npm run test:unit
