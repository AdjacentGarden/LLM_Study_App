# 选择题诊断主线与移动端动效（2026-09-04）

## 本轮实现

- 首页突出“选择题诊断 → 定位薄弱点 → 针对性课程与闪卡”。
- 已完成诊断的用户按有证据的章节掌握估计排序，提供课程及闪卡直达入口。
- 未诊断章节单独标记，不把缺少证据当成薄弱。
- 首题在题库最低难度带选取；答对且有信心、评分可靠时逐步升难度，否则检查基础。
- 稀疏题库按最接近难度选择剩余题，不重复、不阻塞。
- 选项按会话和题目稳定打乱，提交的选项 ID 保持私有计分映射；恢复会话不改变顺序。
- 去除可能包含正确答案的知识点标签，包括从旧持久化会话恢复的数据。
- 已核验为真的陈述与反向题干冲突时，生成阶段拒绝、旧题选取阶段跳过；旧待答冲突题不计入掌握证据。
- 页面入场、诊断逐题切换、选项选中反馈、进度条、底栏滑块、课程标签切换、3D 闪卡翻面、保存提示与生成等待状态。
- 动效采用 CSS transform/opacity，无新增动画运行时依赖；支持系统 reduced-motion。
- 提交期间禁用选项与导航，切换题目重置选项、信心值和滚动位置，首次恢复完成前禁用新建诊断。
- “我的”新增重新诊断入口，不删除服务器已有会话。

## 验证

- 后端 pytest：112 passed（依赖库仍有 6 条弃用警告）。
- Ruff：通过；MyPy：37 个源文件通过。
- 前端 TypeScript/Vite：通过；学习优先级单元测试 4/4 通过。
- 浏览器真实会话：四步背景选择 → 逐题诊断 → 确认方向 → 按掌握估计推荐 → 闪卡直达 → 翻面 → 复习保存 → 返回首页。
- 此次测试跨版本进行：12 次呈现含 1 道旧冲突题，最终 11 次有效作答；旧冲突题没有计入画像。
- 薄弱章初始掌握估计约 14%，打开后采用基础支架编排；测试闪卡复习后前端显示约 20%，并给出下次复习时间。
- 导读、原文、知识、练习、闪卡标签均切换到相符内容；检查了 DOM 动画名称和闪卡变换矩阵。
- 390×844 与 320×740：检查过的诊断页面无文档或内容区横向溢出；390px 下课程全部标签、底部导航目标页面无内容区横向溢出。
- 浏览器错误日志：本轮测试未捕获 error。
- 重新诊断可开启，刷新后能恢复未完成会话。

## 发布范围与限制

- 发布到 4090 数据盘 `/data1/zhenghang/adaptive-book-ocr/app`，没有发布到其他托管平台。
- 发布前备份在同一数据盘的 `release-backups`。不更新 GitHub，不替换书籍，不修改原始 OCR/RAG 数据。
- 测试使用独立浏览器 origin 的新会话，没有覆盖原模拟页的 active-session。
- 当前学习路线是可解释的掌握估计排序；章节课程仍沿用已有的证据化个性化编排器，不是本轮新增的全书自由生成式 AI 长期计划。
- 题库由模型生成并复用；本轮没有重新 OCR 整本书或重新生成整套题。新生成规则对后续生成生效。
- 难度与掌握估计还需要真实学习者数据校准，不能视为专业考试量表。
- CSS 减少动态效果规则已检查，但没有更改用户系统设置进行实机辅助功能验收。
- 本轮并非全 App 上线认证，也不代表所有题目的教学质量已经通过人工逐题审校。
