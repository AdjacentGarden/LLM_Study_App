## 路由结论

该文件不得使用 `pypdf.extract_text()` 或普通 PDF 文本层作为主来源。全部页面进入：

1. 300 DPI 页面渲染、方向和倾斜校正；
2. MinerU 混合 VLM/OCR 版面重建；
3. 低置信块使用第二视觉模型在 420 DPI 复识别；
4. 块级候选对齐与一致性评分；
5. 邻页上下文辅助的 LLM 校对，但禁止补写；
6. 保留页码、坐标、原始候选、修订日志和未决片段；
7. 未通过质量阈值的页不进入 RAG 和课程生成。

这项检测已经实现为 `PDFInspector`，不是针对文件名写死的判断。
