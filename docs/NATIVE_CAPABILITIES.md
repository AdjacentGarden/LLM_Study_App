# 后端能力与原生接入契约

本表描述 2026-10-22 仓库实际接入状态。后端存在接口不代表原生页面已调用。当前客户端保留已有界面；本轮未增加教学单元、服务端计划、社交等产品入口，也未把 fixture/演示响应当成真实服务。

| 能力 | 后端状态 | 当前 SwiftUI 状态 | 真实运行条件 / 边界 |
|---|---|---|---|
| 默认账号 / 邮箱账号 | 持久会话、撤销、验证码、限流 | 本机默认登录与邮箱账号接入 | 默认账号仅回环开发；正式邮箱需要 SMTP；401/account=null 清除离线身份 |
| 多资料课程 / 上传 / 章节结构 | 已实现并按账号隔离 | 已接入 | OCR/章节重建真实运行依赖另配；内置生物课程不需重新生成 |
| 课程、教材阅读、闪卡、练习、答疑 | 已实现 | 已接入 | 教材答疑需真实索引/模型；客观题后端评分；FSRS 事件与状态原子保存 |
| 教学单元（更细粒度教学抽象） | 有领域模型/生成能力 | 未接入为独立教学单元流程 | 原生仍使用现有章节/课时，不把旧课时自动宣称为新教学单元 |
| 服务端学习计划、反馈调整 | 有配置、计划和调整接口 | 尚未接入完整服务端计划/调整流程 | 原生现有计划/任务进度保持原行为，不能把本地展示当成云端计划闭环 |
| 个人笔记 | 后端 Studio 有持久笔记及版本接口 | 现有原生笔记按账号在本机保存 | 当前原生笔记没有云同步；离线成功落盘才显示保存成功；不能声称跨设备笔记已同步 |
| 语音 | 后端有真实转写适配器及能力就绪检查 | 原生已有本地录音/笔记体验，未接真实服务端转写 | `/api/studio/capabilities.voice_notes` 取决于 ASR runtime 和配置；本轮没有对真实 ASR 模型作运行验证 |
| 手写 | 后端 Studio 可持久笔迹和触发识别/核验 | 原生有本地手写笔记体验，未接入服务端识别/检查 | 后端 notes_ai 就绪条件由现有 Studio 能力接口报告；本地笔迹不等于已完成真实识别 |
| 社区 / 社交 / 聊天 | 已有授权、好友关系、资源分享与聊天接口 | 未接入完整真实社区/社交流程 | 原生内置发现目录可用；不能把内置展示内容宣称为真实用户活动 |
| 离线学习 | 服务端仍需正常鉴权 | 已验证身份下恢复缓存、笔记和待同步进度/复习 | 仅网络传输失败允许缓存恢复；未缓存正文需联网加载；明确失效会话不回退缓存 |

`GET /api/native/capabilities` 是新增的向后兼容发现接口（contract_version=1）。其中 `backend` 表示服务端代码支持，`native` 表示该项服务端能力已接入原生，而非本地是否存在相似页面。真实转写/媒体/手写识别的运行就绪状态仍应读取 `/api/studio/capabilities`，不能只凭支持标志显示可用。旧 HTTP 字段、错误含义及旧客户端默认 bootstrap 响应保持兼容。

原生使用 `GET /api/native/bootstrap?mode=metadata`，将课程元数据、进度和复习状态与不可变正文分离。`content_key` 是缓存身份，`content_path` 是正文获取路径；内置课程按版本共享同一正文，个人任务 ID/进度在映射时应用。版本更新或缓存缺失会重新获取正文；离线未缓存资料保留元数据并提示联网。未加 mode 的旧客户端继续得到完整正文。

已验证身份与 cookie 共同存放 Keychain；SQLite 缓存按规范化 origin + user_id 隔离。尾斜杠、显式默认端口可兼容旧缓存；非默认端口、不同账号和服务不会互相读取凭证。升级前没有保存过验证身份的客户端需要先完成一次成功鉴权，才能建立新的离线身份记录；旧 SQLite 笔记/待同步数据会在该次鉴权后按旧 origin key 兼容读取，不会删除。

本机持久化将不可变正文、资源进度、个人笔记和轻量应用状态分开。旧单快照可继续读取，保存时迁移为分层记录。用户注销会清除所有当前 origin 兼容形式的凭证与验证身份；旧缓存文件保留以供同账号后续登录恢复，但不会在未鉴权或另一个账号下自动展示。
