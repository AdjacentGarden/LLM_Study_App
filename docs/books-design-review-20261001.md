# 云径界面整理与本机验证（2026-10-01）

基线：远程 main `b5af3a5`，`git pull --ff-only` 确认已同步。以下改动在本机开发环境验证，验证时尚未发布到服务器。网络连接由运行时端口转发提供，未修改或加入仓库网络配置。

## 参照与设计取舍

参照 [Apple Books](https://www.apple.com/apple-books/) 的书封面优先和阅读内容层级，以及 [Apple 的布局指引](https://developer.apple.com/design/human-interface-guidelines/layout)。采用自己的组件与色彩，不复制 Apple 素材。

- 主页面使用一致的大标题、暖白背景、细分隔线和单一蓝色操作强调。
- 首页明确显示当前书封面、书名、章节数和一个主要学习动作；上传入口保留在首页。
- 章节采用编号列表；移除重复的“尚待诊断”、默认说明和需额外解释的圆环，展开后仍能查看掌握估计与依据。
- 书架移除重复标题和“继续阅读”提示，保留搜索、筛选、封面预览、管理与分享。
- 社区合并好友与分享入口，保留书籍、笔记两个分类，去掉重复分类标题。
- 我的页面突出账号和可点击的学习记录，取消各指标独立大色块。
- 课程编排解释收进“学习建议”；手写操作说明折叠。保留错误提示、处理状态、隐私与分享权利说明。
- 修复笔记面板选中“笔记”时标题仍显示“生成图解”的问题；使用统一线性图标。

## 模型优化与边界

1. 答疑已验证结果的进程内缓存由 5 分钟、64 条扩展为 30 分钟、128 条。缓存仍属于对应教材索引/模型服务，保留过期和容量限制、深拷贝、并发合并；拒答和失败不缓存。
2. 独立语义复核仅传递被引用页及相邻页的完整检索段落，保留同页多段、否定条件和跨页语境。初次回答仍使用全部检索材料。
3. 复核/初稿 JSON 输入去掉无意义格式空白；HTTP 连接保活由默认 5 秒扩展为 60 秒，池容量仍有界。
4. 没有移除逐字引文核验或语义复核，没有为了缩短时间提前展示未经审查的内容。

本机使用真实 PUCODING `gpt-6-sol`，对同一批教材证据做两道题的前后对照。是固定证据的模型阶段测试，不含 GPU 检索；每次独立生成，答案长度和上游负载可能不同，样本量不足以建立 P95 或总体性能结论。
