# 模块 4：主动式学习者诊断与可恢复画像

## 目标

本模块不是让用户填写一张静态问卷，而是在不把模型推测当事实的前提下，主动了解学习目标、重点章节、已有背景、可用时间和真实知识掌握情况。所有结论都区分“用户自述”和“实际作答证据”，未知项继续保持未知。

## 技术路线

- 用四步短访谈收集目标、真实章节偏好、背景层级和每日时间；章节选项来自当前书籍结构，不使用演示数据。
- 自述背景只形成低权重 Beta 先验，`evidence_count` 保持为 0，不能冒充实际掌握证据。
- 诊断题从每章的逐字原文证据生成。先按概念价值筛掉年份、人名等低价值记忆点，再用独立审题调用检查可回答性、歧义、干扰项和评分细则。
- 选择题的正确项由后端强制替换为已经核验的知识点；解释题参考答案同样锁定到已核验知识点，模型不能自行创造答案事实。
- 选择题干扰项过短、会靠视觉长度泄露答案时，程序拒绝整批输出并要求模型重试；冷启动诊断不再降级成开放题。
- 选题使用 IRT Fisher 信息量、Beta 后验期望信息增益、未覆盖知识、章节多样性、用户重点和作答成本联合排序。
- 画像更新同时考虑评分置信度、题目区分度、提示次数、异常快速作答和反复修改；用户信心通过 Brier 误差单独记录。
- 冷启动画像只发布选择题；开放解释评分仅保留给正式课程练习，不参与首次摸底。
- 最多 12 道冷启动题，未覆盖部分不会被填成“不会”，而是在正式学习中继续校准。

## 隐私与防作弊

内部 `DiagnosticItem` 与前端 `PublicDiagnosticItem` 完全分离。任何访谈响应和恢复接口都不返回：

- `correct_option_ids`
- `expected_answer`
- `rubric`
- 内部证据页与评分密钥

答案只保存在数据盘 SQLite 中。前端只获得题目、可见选项、预计时长和普通用户能理解的提问原因。

## 持久化与并发

- `diagnostic_banks` 按书籍结构指纹持久化；结构变化后旧题库自动失效。
- `interview_sessions` 保存完整访谈阶段、待答题目、画像证据和修订号。
- 会话更新使用乐观锁，两个客户端同时覆盖同一画像时返回冲突，不会静默丢数据。
- `POST /next` 在已有待答题时幂等返回同一道题，重复请求不会跳题。
- 后端重启后可从同一个 `turn_id` 和题目继续。

## API

- `POST /api/books/{book_id}/diagnostics`：生成并持久化证据化诊断题库。
- `GET /api/books/{book_id}/diagnostics`：只返回题库覆盖统计，不泄露题目答案。
- `POST /api/interviews/start`：基于真实书籍与持久化题库开始主动访谈。
- `POST /api/interviews/{session_id}/profile`：提交目标、章节、背景或时间。
- `POST /api/interviews/{session_id}/next`：取得自适应选择的下一题。
- `POST /api/interviews/{session_id}/respond`：评分并更新画像；必要时返回一次澄清追问。
- `GET /api/interviews/{session_id}`：在刷新、换端或服务重启后恢复。
- `POST /api/interviews/{session_id}/confirm`：用户确认初步画像。

## 验证门禁

- 当前 101 项后端测试全部通过；Ruff、MyPy strict 和前端 TypeScript/Vite 构建全部通过。
- 单元测试覆盖信息增益选题、重点章节偏好、掌握后验、信心校准、提示/异常速度降权、答案密钥隔离、开放回答追问、幂等取题、SQLite 重启恢复和乐观锁冲突。
- 30 个会话、12 并发工作线程同时完成开始访谈、4 次画像写入、取题与恢复：30/30 成功、会话 ID 30/30 唯一，耗时 11.04 秒。
- 错误但高信心的真实选择题得到 0 分，Brier 误差为 0.9025，对应知识后验均值降至 0.3212。
- “因为本来就是这样，我不太清楚”真实开放回答得到 0 分并触发针对性追问，没有被误判为掌握。
- 历史题库中混合存在的解释题会被视为旧格式并触发重新生成；API 恢复时也会再次过滤，不能把旧开放题送回客户端。
- 新生成题库只接受四选一选择题；正确项逐字等于已核验知识点，视觉长度异常会导致整题拒绝而不是发布。
- 完整教材真实自适应访谈完成 12 道不重复题，覆盖 6/6 章；黄金回答 12/12 均得到 1.0，开放题无不必要追问，最终进入用户确认阶段。
- 题库 SQLite 原始 JSON 在后端重启前后 SHA-256 完全一致；已完成的 12 题会话在重启后仍保留 12 条诊断观察和 16 条画像证据。

## 诚实边界

当前冷启动画像是“足够开始个性化课程的初步画像”，不是一次性永久结论。未覆盖知识点会明确保留，后续课程练习、闪卡和问答行为还必须继续更新同一后验；这部分属于模块 5。
