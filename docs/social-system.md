# 好友与私信：实现与边界

## 当前实现

- 社区页「好友与消息」入口，保持原有五个主导航；个人资料中展示不可修改的用户 ID。
- `ZW-` + 10 位随机十六进制公开 ID，SQLite 唯一索引、冲突重试。原有访客增量迁移，不覆盖头像、昵称、书架、学习数据。
- 昵称可以重复；按昵称模糊查找或完整 ID 精确查找。默认不公开，用户开启「好友查找」后才展示昵称、头像、ID。年龄、个人简介、学习画像不对外返回。
- 双向好友申请：接受、婉拒、撤回、删除、屏蔽、解除屏蔽。拒绝后 24 小时冷却；每分钟最多 5 次新申请。关闭查找不影响现有好友。
- 只有双方成为好友后才能发消息。删除/屏蔽停止新消息，已有双方会话和已收藏副本保留。屏蔽后互相无法查找。
- UTF-8 文本私信，上限 2000 字符；每分钟最多 60 条。服务器持久化会话、消息和已读位置。客户端前台 3 秒增量轮询，后台暂停、异常 5 秒重试；不是 WebSocket，也不提供离线推送。
- 消息游标按 SQLite 整数主键单调递增，每页 50 条；支持历史回翻和断线增量补齐。幂等发送标识 + 请求指纹，网络超时后重试不重复插入，即便笔记原作者随后修改了原内容，仍返回最初发送的快照。
- 分享五类内容：书籍、闪卡（可选部分）、私人笔记、章节总结、知识点清单。客户端仅提交本人已持有内容的引用；服务端检查书籍/资料/课程所属权并构造快照，不能伪造正文或发送别人的资源。
- 接收书籍以 canonical 内容指纹去重，复用服务器 PDF/OCR/RAG，不复制对方学习进度。其他分享收藏到「闪卡与笔记」，同一消息重复收藏不重复，归档后可恢复。章节摘要/知识点存为笔记型资源。
- 私信分享不创建社区公开帖子。发送前确认传播权；明确提醒接收者可以保存副本。

## 安全与持久化

沿用现有 HttpOnly、SameSite=Lax 访客 Cookie，服务端只保存令牌哈希。公开用户 ID **不是登录凭证**，不能据此读取资料或私信。所有写入做 Origin 同源检查；消息/附件领取只允许会话参与者。消息与好友关系写入使用 SQLite `BEGIN IMMEDIATE` 防止并发重复及屏蔽竞态。

新增表：`social_users`、`friendships`、`social_blocks`、`chat_messages`、`chat_reads`、`social_rate`。位于原有数据盘 `data/state/community.sqlite3`，WAL 模式；按会话游标、发送者时间和会话参与人建立索引。不涉及 OCR、RAG、模型密钥或已有学习数据库的重建。

## 明确限制：仍是受控预览，不是正式账号系统

现阶段一个浏览器身份对应一个公开用户 ID。清除 Cookie、换浏览器/设备不会自动登录回原身份，尚无手机号/邮箱登录、找回、账号合并。用户 ID 不是跨设备恢复码。旧学习接口沿用不透明 session capability，首次分享会将 session 绑定当前访客；这不等价于完整的全站账号鉴权改造。

对公网正式发布前应补齐 HTTPS、可恢复账号、跨设备会话管理、旧学习会话的账户迁移与统一鉴权、举报审核、注销/导出与保留政策，以及负载和滥用监控。当前 HTTP 地址仅用于可信网络下测试。私信不做端到端加密，不承诺服务器运营者无法读取。

## 测试与部署

后端 `tests/test_social.py` 覆盖：公开 ID/凭证隔离、迁移、同名搜索、隐私字段、双向同意、拒绝冷却、限流、第三方越权、CSRF、并发幂等、分页补齐、已读单调更新、删除/屏蔽、头像可见性、五类附件、不可变副本及去重。

前端 `tests/social.test.ts` 覆盖乱序合并、回显去重和非安全 HTTP 上的随机发送标识。部署沿用 4090 数据盘目录；先保存源码/构建和 SQLite 在线备份，再增量同步并重启自己的后端服务。

复验命令（需在受控预览环境运行）：

```sh
cd backend
.venv/bin/pytest
.venv/bin/ruff check src tests/test_social.py
.venv/bin/mypy src
cd ../frontend
npm ci
npm run build
npm run test:unit
npx playwright install webkit
SOCIAL_E2E_BASE_URL=http://127.0.0.1:18100 npm run test:e2e
cd ..
backend/.venv/bin/python deployment/server/smoke_social.py
```

浏览器验收用两个独立临时 Cookie 身份，实际点击查找、申请、接受、聊天、分享、收藏、重复收藏、屏蔽及解除屏蔽；模拟发送回包丢失，检查重试仅产生一条消息；覆盖刷新恢复、历史翻页和 iPhone 16 等比缩放。测试结束关闭测试身份可发现性，不更改真实用户资料。聊天记录截图和失败 trace 仅保留在被忽略的 `frontend/test-results`，不提交到仓库。
