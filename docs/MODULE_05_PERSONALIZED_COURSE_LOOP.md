# 模块 5：证据化个人课程与持续掌握闭环

## 目标

同一本书不能只生成一套固定课。本模块把已确认的学习目标、章节掌握后验、尚未知知识、信心校准和每日时间编译成章级个人课程；练习与闪卡反馈继续更新同一画像，只让受影响章节产生新版本。

## 可靠课程编译

课程事实不交给模型自由发挥。`ChapterCourseCompiler` 只消费模块 3 已核验的章节摘要、知识点和逐字原文证据：

- 掌握不足的知识点优先，其次是尚未验证的内容，再到复习内容；
- `FOUNDATION` 最多 12 个知识点，强调术语、步骤和低门槛回忆；
- `STANDARD` 最多 8 个知识点，强调结构联系；
- `ADVANCED` 最多 6 个知识点，减少重复讲解，强调完整关系与易混点；
- 每日时间进一步限制单次知识点数量，未选内容明确进入后续单元；
- 章节总结逐字使用已核验摘要；知识点解释、闪卡背面和练习参考答案逐字使用已核验知识点；
- 原文阅读是经过 OCR 清洗并已通过证据门禁的可读片段，每条都带页码；
- 所有课程事实都有对应的 `SourceCitation`，内部块 ID 不出现在用户界面。

## 课程组成

每章公开课程包含：

- 面向当前目标与难度的开场说明；
- 已核验章节总结；
- 有页码的精选原文阅读；
- 按当前优先级排序的知识点、掌握状态和来源；
- 闪卡及“为什么推荐给你”；
- 原文证据拆解；
- 随堂练习和预计学习时间。

练习答案、评分量规、画像指纹、来源指纹和内部块 ID 只保存在服务端。公开课程模型与私有课程模型分离，不能靠前端查看网络响应获得答案。

## 持续更新

- 开放练习由 DeepSeek 按已核验答案与量规评分；低评分置信度不更新画像。
- 闪卡使用 `again / hard / good / easy` 四档反馈和改进的 SM-2 间隔计划。
- 闪卡自报只按 0.55 置信度写入行为证据，权重低于真实诊断题，避免“点一下会了”过度抬高掌握度。
- 每个学习事件必须带唯一 `event_id`；事件记录与画像修订在同一 SQLite 事务内提交。
- 重复或网络重试返回第一次结果，不会重复加分、重复延长复习间隔。
- 画像或章节来源发生变化后，旧课程标记为过期；再次编译只生成该章下一版本。
- 旧版本保留，可审计、比较和回滚。

## 并发收敛

课程 ID 由会话、章节来源指纹和画像指纹确定，同一状态下不受请求先后或计算版本号影响。并发请求即使在“读取最新版”和“写入”之间交错，最终也会收敛到同一个课程 ID 与版本。

## API

- `POST /api/interviews/{session_id}/courses/{chapter_id}`：画像确认后生成课程；相同输入幂等返回现有版本。
- `GET /api/interviews/{session_id}/courses/{chapter_id}`：读取该会话该章最新版。
- `POST /api/interviews/{session_id}/courses/{course_id}/practice/{item_id}`：提交练习并更新画像。
- `POST /api/interviews/{session_id}/courses/{course_id}/flashcards/{card_id}`：提交闪卡反馈并更新间隔计划。

## 验证门禁

- 95 项后端测试、Ruff、MyPy strict、前端 TypeScript/Vite 构建全部通过。
- 覆盖不同掌握度的深度切换、薄弱/未知知识排序、时间预算、逐字证据、答案隔离、课程指纹、无证据拒绝、间隔复习、原子事件与跨会话事件隔离。
- 完整生物教材的已确认画像成功生成 6/6 章个人课程，共 36 个知识点、36 张闪卡、36 道练习。
- 6 章最新版课程合计 276 条引用，276/276 均逐字匹配对应章节已核验原文；6/6 章节摘要完全一致。
- 36/36 个知识点解释、36/36 个闪卡答案和 36/36 个练习答案均来自已核验知识点。
- 检查 6 个公开课程响应，答案、量规、画像指纹、来源指纹和内部块 ID 泄露数为 0。
- 真实开放练习黄金回答得到 1.0，更新画像后 `course_stale=true`；同一事件重复提交只增加 1 条观察。
- 真实闪卡 `good` 反馈产生 1 天后复习计划；重复提交不重复排期。
- 更新后该章从版本 1 生成版本 2，已经巩固的知识点退出前 6 个优先集合，其他尚未知内容自动补位；重复编译返回同一版本。
- 40 个请求、20 并发线程同时生成同一章：40/40 成功、结果唯一数 1、数据库课程行数 1。
- 20 个并发请求同时提交同一个闪卡事件：20/20 返回 200，仅 1 个为首次提交、19 个为重复结果，画像观察只增加 1。
- 服务重启后课程 JSON 与重启前完全一致，旧版本与新版本均保留。
