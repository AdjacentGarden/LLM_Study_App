# 语音笔记实现说明

语音笔记与手写笔记共享同一套教材核验、整理和版本管理，不另建一套低质量的“语音摘要”。用户可以直接录音，也可以选择已有音频；主操作仍是一次“完成并整理”。

处理链路：

1. 原始录音以用户隔离目录保存在数据盘，接口鉴权后才能读取，响应禁止公共缓存。
2. `faster-whisper-small` 在 4090 服务器的 CPU 上以 INT8 离线转写；静音由 VAD 过滤，当前章节标题和选段仅作为术语提示。
3. 低置信度词或无有效语音会停在确认步骤，系统不猜测；清晰语音直接继续。
4. 逐字稿进入现有 RAG，从当前教材取回证据，再由文本模型做局部纠错、补全和结构整理。
5. 第二次模型调用复核事实、因果、否定和教材引用。原始录音、逐字稿、整理版各自保留，整理版不会覆盖原话。

边界与保护：单条最长 10 分钟、最大 20 MB；校验文件签名而非只信扩展名；上传和分析都带笔记版本号；同一音频的超时重试按 SHA-256 幂等处理。支持 WebM/Opus、WAV、M4A/MP4、MP3/AAC、Ogg、AIFF、FLAC 和 CAF。

生产配置见 `.env.example` 中的 `VOICE_ASR_*`。ASR 运行在隔离的 Python 3.8/CTranslate2 环境，不占用当前已高负载的四张 4090；RAG 在 GPU 显存不足时会自动回落到 CPU，避免整个 API 因其他训练任务而离线。
