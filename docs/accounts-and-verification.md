# 邮箱账号、验证码与演示好友

## 用户流程

首次打开显示注册页：邮箱、验证码、昵称、学习阶段、兴趣方向和学习目标；已有账号使用邮箱验证码登录，不设置密码。可以暂时体验。旧访客不会被强制退出，仍保留原来的资料、书架、好友与学习记录，可从「我的」注册绑定。

注册绑定原访客身份，公开用户 ID 不变。跨浏览器登录相同邮箱恢复相同账号、好友与消息；绑定的学习会话按书恢复。学习阶段和兴趣只作为初始偏好，不替代知识诊断结果，不公开给好友。

同源标签页通过 BroadcastChannel 同步登录/退出。浏览器缓存按账号 ID 隔离；旧缓存只迁移一次，异步请求保留发起时的缓存作用域，避免切换账号时串写。

## 后端与安全

- `/api/auth/me`、`code`、`verify`、`logout`、`demo-friends`。
- 6 位验证码，10 分钟有效、一次性消费、最多错误 5 次；60 秒重发间隔，每邮箱每小时 5 次，每来源 IP / 访客每小时 60 次。挑战绑定发起浏览器。
- 数据库只保存验证码 HMAC、会话令牌哈希。独立验证码密钥文件 `data/state/account-otp.key`，权限 0600；需随服务器安全备份，不提交仓库。
- 会话 30 天，HttpOnly / SameSite=Lax；HTTPS 下设置 Secure。退出撤销当前会话。注册后旧访客令牌失效。
- 账号与绑定学习会话做权限校验，写请求检查 Origin；私信继续限制为好友双方。未绑定的旧学习会话仍兼容原有不透明 capability，尚未完成全站历史接口迁移。

## 真实邮件配置

当前 4090 未配置发信服务。真实邮箱申请验证码会明确报服务未开通，不会假装邮件已发送；测试通过的是演示通道与模拟 SMTP 单元测试，**不是实际邮件投递验收**。

在服务器秘密配置 `secrets/adaptive-book.env` 配置以下环境变量，不写入 Git：

```dotenv
SMTP_HOST=your-smtp-host
SMTP_PORT=465
SMTP_SECURITY=ssl
SMTP_FROM=your-verified-sender
SMTP_USER=your-smtp-user
SMTP_PASSWORD=your-smtp-app-password
```

也支持 `SMTP_PORT=587`、`SMTP_SECURITY=starttls`。两种模式均验证 TLS 证书。配置后重启 `deployment/server/run_backend.sh restart`，必须用受控真实邮箱测试收信、延迟、重发和过期。正式发布还需检查发信域名认证、退信与额度；未接入图形验证码供应商，当前防滥用为邮件验证码与限流。

## 私有预览演示
