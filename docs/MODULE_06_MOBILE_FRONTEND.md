# 模块 6：移动端前端与全栈交互验收

## 模块边界

本模块把已经通过门禁的 OCR、RAG、主动画像和个性化课程能力接入真实移动端页面。页面不使用演示假数据；教材、章节、诊断、课程、练习、闪卡与问答均调用 4090 上的生产 API。

## 交付内容

- 独立的学习首页、云端书架、主动诊断、章节课程、教材答疑和个人设置页面。
- 书架仅展示服务器发布目录中的《生物 必修2 遗传与进化》，正文与索引不保存在手机本地。
- 诊断覆盖目标、重点章节、背景、时间约束、自适应题、针对性追问与画像确认。
- 课程覆盖导读、原文摘录、知识点、闪卡、随堂练习和画像变化后的版本刷新。
- RAG 答疑使用独立滚动回答区，建议与输入框固定在底部；每条结论展示教材页码和原文。
- 学习提醒和字体大小可即时修改，并持久保存在浏览器本地偏好中。
- 390×844 与 430×932 两档移动视口适配，触控目标最小 44 px，无横向溢出。

## 实测发现并修复的回归

1. “书架”原本与“学习”指向同一页面，已拆为真实独立书架。
2. 新增目录接口时曾把上传接口的持久化返回放到不可达位置，已恢复并由上传测试覆盖。
3. 长 RAG 回答会把输入框推到数屏之后，已改为回答区独立滚动、输入区固定。
4. 闪卡证据会误显示为尚未作答练习的成绩，已在切换标签时隔离反馈。
5. 清除当前练习反馈时会同时丢失“课程需刷新”状态，已拆分两个状态。
6. 重进课程会读取旧版本而不校验画像，已统一通过后端幂等编译接口校验画像指纹。
7. 重复引用显示为“第20、20页”，已统一去重页码。
8. PDF 跨页句子被误认为 OCR 缺字；经原 PDF 页图核验后，改用“原文摘录”和省略号表示边界，未篡改源文本。
9. 已完成画像的入口进入禁用按钮死路，已改为“返回个性化课程”。
10. 原生时间与滑块在部分移动 WebView 中 `change` 事件不稳定，已改用即时 `input` 事件并验证持久化。

## 模块门禁

- `npm run build` 必须通过 TypeScript 构建和 Vite 生产打包。
- 后端 95 个测试、Ruff、mypy 严格模式必须同时通过。
- 真实浏览器流程必须覆盖本页表格中的所有交互。
- 未通过最终压力、进程重启、健康检查与发布验收前，不进入“完成”状态。
