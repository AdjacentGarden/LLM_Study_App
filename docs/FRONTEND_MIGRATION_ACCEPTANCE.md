## 验收发现与修正

1. 上传任务按 `uploaded → bound → processing → structuring → claiming → diagnostics` 持久化，失败后继续正确阶段；已捕获账号存储身份，卸载时使旧请求失效。
2. 领取采用最终 canonical ID，并要求刷新后的个人书架实际包含它。诊断完成后再次刷新目录状态。
3. 页图失败增加提取文字回退与图片重试。
4. 练习结果绑定当前 item，闪卡结果绑定当前 card，避免反馈串题；切卡后另显示上一张保存成功的提示。
5. 学习 event_id 按账号、会话、课程版本和题目持久化，失败/刷新重试复用同一事件；服务端确认成功后释放，新一次作答或复习生成新事件并重新评分。
6. 修正安静刷新覆盖旧请求时 busy/initializing 不释放的问题，移出书架和旧请求返回均检查当前上下文。
7. 新弹层增加焦点循环及焦点恢复，切页重置实际文档滚动，闪卡增加有水平意图判断的手势。
8. 课程恢复后仍提供“按当前画像检查更新”，通过现有 POST 指纹检查复用或更新课程。
9. `GET /api/library` 改为依据当前章节结构指纹匹配的单选诊断题库动态计算 `diagnostics_ready`，修复 claim 时保存的旧值使新教材无法开始诊断的问题；同时覆盖结构变化后失效、只有开放题、去重后 canonical ID 等边界。主代理执行相关 22 项后端测试及真实上传 UI 复验均通过。
